## 1. 风险等级

| 等级 | 典型改动 | 最低门禁 | 说明 |
| --- | --- | --- | --- |
| L1 | 文案、说明、低风险样式 | 对应文件检查；必要时跑局部测试 | 不影响数据和接口。 |
| L2 | 普通页面展示、筛选、弹窗 | 页面相关测试；`npm run guard:test-inventory` | 不能改业务事实和财务口径。 |
| L3 | 统一读模型、字段、指标、权限、导出 | `npm test`；口径相关测试；`npm run guard:test-inventory` | 必须说明影响页面、接口、表和指标。 |
| L4 | 课包、权益、排课、订场、会员、财务展示 | `npm test`；`npm run guard:finance`；`npm run guard:release` | 默认高风险，不能只测目标页面。 |
| L5 | 生产写入、导入、修数、财务补账、回滚 | L4 全部门禁；生产数据流程；操作前后快照；线上接口和页面核对 | 功能开发和修数必须分流。 |

## 2. 发布门禁组成

1. `npm test`：默认业务、页面、口径和结构测试。
2. `npm run guard:test-inventory`：检查新增测试是否进入脚本或登记原因。
3. `npm run guard:deps-security`：依赖安全门禁。
4. `npm run guard:finance`：财务固定样本回归。
5. `npm run guard:api-smoke`：只读接口冒烟；未配置真实环境时只说明未配置，不能冒充线上验收。
6. 发布补充测试：页面数据、权限、性能、生产读写保护等专项测试。

## 3. 升级规则

1. 只要触达财务、课包、权益、订场、会员，最低按 L4。
2. 只要写生产、导入、修数、回滚，最低按 L5。
3. 用户说“全局、全部、统一、所有页面”时，最低按 L3。
4. 任何绕过门禁、删除测试、放宽断言的改动，自动升级一级。
