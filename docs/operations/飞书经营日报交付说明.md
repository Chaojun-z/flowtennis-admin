## 1. 日报定位

飞书经营日报面向老板和管理员，第一版只展示数据，不输出机器结论、经营建议或风险判断。

日报固定包含：

- 整体经营：今日、昨日、近 7 日均值、本月累计。
- 校区数据：实收、核销、成交、上课核销、待履约。
- 收入结构：课包收入、订场收入、会员储值。
- 核销结构：课程核销、散客订场核销、会员订场核销。
- 明日已排：课程数、预计上课学员数、预约体验课数。

## 2. 数据口径

经营日报不单独重新定义财务口径。

取数链路：

```text
TableStore 只读表
-> scripts/export-business-daily-report-json.js
-> api/index.js 的 buildFinancePageSnapshot
-> scripts/lib/business-daily-report.js
-> standalone-services/feishu-business-report.js
-> 飞书群机器人
```

核心原则：

- 实收、核销、待履约来自统一财务流水快照。
- 校区统计按业务发生校区统计，不按客户主校区倒推。
- 差异项不进入日报经营数字。
- 机器人消息层只负责格式化，不参与财务计算。

## 3. 定时任务

GitHub Actions 文件：

```text
.github/workflows/feishu-business-daily-report.yml
```

默认推送时间：

```text
每天 UTC 14:20
北京时间 22:20
```

定时任务使用只读 TableStore 密钥，禁止生产写入：

```text
ALLOW_PRODUCTION_BOOTSTRAP_WRITES=false
```

## 4. 上线前配置

GitHub Secrets 需要配置：

```text
FEISHU_BUSINESS_DAILY_REPORT_WEBHOOK
TABLESTORE_READONLY_ENDPOINT
TABLESTORE_READONLY_INSTANCE
TABLESTORE_READONLY_ACCESS_KEY_ID
TABLESTORE_READONLY_ACCESS_KEY_SECRET
```

`FEISHU_BUSINESS_DAILY_REPORT_WEBHOOK` 必须是经营日报群的飞书机器人 webhook，不要复用排课日报 webhook，避免发错群。

## 6. 当前边界

第一版不包含：

- AI 经营结论。
- 异常自动判断。
- 管理员明细追踪入口。
- 前端页面配置开关。

这些能力后续可以单独迭代，不能直接混进本版经营日报口径。
