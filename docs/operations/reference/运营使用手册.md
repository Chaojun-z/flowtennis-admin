# FlowTennis 运营使用手册

这份手册不讲代码，只讲日常怎么用。

适合谁看：

- 新运营
- 新同事
- 未来接手这个项目的人

目标：

- 让一个第一次接触系统的人，知道“我今天该去哪个页面做什么”

---

## 一、先记住：这个系统分两条线

### 1. 教学线

你在处理：

- 学员
- 课程
- 课包
- 购课
- 排课
- 教练反馈

### 2. 场地会员线

你在处理：

- 订场用户
- 会员方案
- 会员开卡/续充
- 会员余额
- 会员权益

---

## 二、每天最常用的页面

如果你是运营，优先记这 7 个页面：

1. 学员信息
2. 排课表
3. 教练运营
4. 购买记录
5. 权益账户
6. 订场用户
7. 会员管理

其他页面很多是配置页或追溯页，不一定天天用。

---

## 三、日常场景怎么操作

## 场景 1：新增一个学员

去哪里：

- `学员信息`

怎么做：

1. 搜索一下名字和手机号，先确认系统里没有重复学员
2. 点击“添加学员”
3. 填基础信息
4. 保存

做完后你还能去哪里看：

- `班次管理` 看他有没有进班
- `购买记录` 看他有没有买课
- `权益账户` 看他有没有课时

注意：

- 学员一旦已经进入班次、购买、排课、反馈链路，就不能随便删除

---

## 场景 2：给学员卖课

去哪里：

- `购买记录`

前提：

- 学员必须已经存在
- 售卖课包必须已经存在且启用

怎么做：

1. 确认学员已经在 `学员信息`
2. 确认课包已经在 `售卖课包`
3. 到 `购买记录` 新增购买
4. 选择学员
5. 选择课包
6. 填购买日期、实收金额、支付方式
7. 保存

系统会自动做什么：

- 自动生成一条 `权益账户`

你下一步要去哪里看：

- `权益账户` 看课时余额是否生成成功

注意：

- 如果这笔购买已经发生过课时消耗，后面不能随便改学员和课包

---

## 场景 3：给学员排课

去哪里：

- `排课表`
- 或者 `教练运营`

怎么做：

1. 先确认学员存在
2. 先确认班次存在
   如果这是班课/长期课，建议先有班次
3. 在 `排课表` 新增排课
4. 选择日期、开始时间、结束时间
5. 选择学员
6. 选择班次
7. 选择教练
8. 选择校区和场地
9. 选择课程类型
10. 如果是要扣课的课，绑定或确认权益账户
11. 保存

系统会自动校验什么：

- 教练是否时间冲突
- 场地是否冲突
- 学员是否时间冲突
- 权益是否可用

系统会自动影响什么：

- 权益账户余额
- 班次已上课时
- 学习计划进度
- 教练端工作台 / 我的课表

注意：

- 多人排课目前不支持绑定一个单独权益账户
- 如果这节课已经有反馈，很多核心字段就不能再乱改

---

## 场景 4：看某个学员还剩多少课

去哪里：

- `权益账户`

怎么看：

1. 搜索学员
2. 看对应权益账户
3. 重点看：
   - 总课时
   - 已用课时
   - 剩余课时
   - 有效期
   - 状态

如果要追溯为什么变少了：

- 看 `权益流水`

注意：

- 不要把“购买记录”当成余额页
- 买了多少，看 `购买记录`
- 还剩多少，看 `权益账户`

---

## 场景 5：看教练最近忙不忙，有没有漏反馈

去哪里：

- `教练运营`

怎么看：

1. 看日 / 周 / 月视图
2. 看某个教练的时间轴
3. 看工作量面板
4. 重点看：
   - 课数
   - 总时长
   - 未反馈数
   - 校区分布
   - 风险提醒

如果要让教练自己处理：

- 教练去 `工作台`
- 教练去 `我的课表`

---

## 场景 6：给订场用户开会员

去哪里：

- `会员管理`
- 或从 `订场用户` 进入会员账户面板

前提：

- 订场用户必须已经存在
- 会员方案必须已经存在且可售卖

怎么做：

1. 确认 `订场用户` 已存在
2. 确认 `会员方案` 已配置好
3. 打开对应用户的会员账户面板
4. 选择会员方案
5. 填购买日期、充值金额等
6. 保存

系统会自动做什么：

- 生成或更新会员账户
- 生成会员订单
- 写入订场财务历史
- 写入赠送权益流水

你下一步去哪里看：

- `会员管理` 看当前会员状态
- `会员购买记录` 看开卡历史
- `会员权益流水` 看权益变化

---

## 场景 7：看会员为什么少了一次权益

去哪里：

- `会员权益流水`

怎么看：

1. 搜索客户
2. 找对应权益名称
3. 看：
   - 变动值
   - 动作类型
   - 操作账号
   - 原因
   - 时间

动作常见含义：

- `grant`：赠送
- `consume`：使用
- `supplement`：补发
- `adjust`：调整
- `void`：作废

## 四、常见问题去哪里看

### 1. 学员资料有问题

去：

- `学员信息`

### 2. 班次不对、学员没进班

去：

- `班次管理`
- `学习计划`

### 3. 这节课到底排没排上

去：

- `排课表`
- `教练运营`

### 4. 学员买了什么课

去：

- `购买记录`

### 5. 学员还剩多少课

去：

- `权益账户`

### 6. 场地客户余额不对

去：

- `订场用户`
- 财务流水弹窗

### 7. 会员现在是什么状态

去：

- `会员管理`

### 8. 会员为什么变动

去：

- `会员购买记录`
- `会员权益流水`

## 五、运营最容易搞错的地方

### 1. 课程产品 和 售卖课包不是一回事

- 课程产品：课是什么
- 售卖课包：课怎么卖

### 2. 购买记录 和 权益账户不是一回事

- 购买记录：买了
- 权益账户：还剩多少

### 3. 班次 和 排课不是一回事

- 班次：长期班
- 排课：某一天某节课

### 4. 学员 和 订场用户不是一回事

- 学员：上课的人
- 订场用户：场地客户

### 5. 会员方案 和 会员管理不是一回事

- 会员方案：卖什么
- 会员管理：谁买了

---

## 六、遇到异常时先怎么判断

### 1. “买了课但看不到余额”

先检查：

1. `购买记录` 有没有新增成功
2. `权益账户` 有没有自动生成
3. 这笔购买有没有被作废

### 2. “排课保存失败”

先检查：

1. 教练是否冲突
2. 场地是否冲突
3. 学员是否冲突
4. 权益是否可用
5. 开始结束时间是否合理

### 3. “班次改不了”

先检查：

1. 这个班次是否已经有排课
2. 是否在改核心字段
   例如课程、教练、校区、学员、总课时

### 4. “购买记录改不了”

先检查：

1. 这笔购买对应的权益是否已经产生消耗流水

### 5. “会员状态看起来怪”

先检查：

1. `会员管理`
2. `会员购买记录`
3. `会员权益流水`
4. 是否发生了自动延续或自动清零

## 七、最短记忆版

如果你只想记最短的一版：

### 教学线

`学员 -> 买课 -> 看权益 -> 排课 -> 看反馈`

对应页面：

`学员信息 -> 购买记录 -> 权益账户 -> 排课表 -> 教练运营`

### 会员线

`订场用户 -> 开会员 -> 看会员状态 -> 查权益变化`

对应页面：

`订场用户 -> 会员管理 -> 会员购买记录 / 会员权益流水`
