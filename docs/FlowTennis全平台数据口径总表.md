# FlowTennis 全平台数据口径总表

> 当前版本：2026-06-26
> 文档定位：全平台唯一数据口径文档。
> 适用范围：客户中心、线索池、留存与转化、经营分析、教学中心、订场用户、会员管理、财务中心、教练端、小程序和后续新增报表。

---

## 1. 文档原则

1. 本文档是全平台数据口径的第一事实源。
2. 页面、接口、读模型、经营分析和导出报表不得各自定义同名指标。
3. 同一个业务含义只能有一个指标名、一个计算公式、一个去重规则、一个排除规则。
4. 原始业务表可以分开存，但客户必须通过统一客户 ID 串联。
5. 页面只展示统一读模型算好的结果，不在页面临时拼口径。
6. 新增指标前，必须先补本文档，再补读模型、接口、页面和测试。
7. 如果旧文档、旧草案、旧代码注释与本文档冲突，以本文档为准。

## 3. 统一基础口径

### 3.1 口径总表字段说明

后续所有指标都按这张表的字段补充。

| 字段 | 含义 |
|---|---|
| 口径 ID | 指标唯一编号，后续读模型和测试可引用 |
| 指标名 | 页面和文档统一展示名称 |
| 归属模块 | 客户、线索、教学、订场、会员、财务等 |
| 指标用途 | 这个指标回答什么业务问题 |
| 分子 | 指标上面的数 |
| 分母 | 指标下面的数；人数指标可为空 |
| 去重规则 | 按客户、订单、课包、场次还是流水去重 |
| 时间口径 | 按创建时间、成交时间、上课时间、订场时间还是储值时间 |
| 排除规则 | 哪些数据不能算进去 |
| 权威数据来源 | 后续实现时必须读取的事实源或统一读模型 |
| 页面使用 | 哪些页面展示或调用 |
| 当前状态 | 已固化 / 待补充 / 禁用 |

### 3.2 全局统计规则

| 规则 | 统一定义 |
|---|---|
| 人数指标 | 默认按客户 ID 去重，不按线索条数、订单条数或手机号条数直接相加 |
| 金额指标 | 默认按有效业务流水或财务流水计算，后续财务章节补全 |
| 时间筛选 | 默认按指标自己的业务发生时间，不统一混用创建时间 |
| 统计范围 | 用户在页面选择的开始时间到结束时间 |
| 统计截止时间 | 用于判断统计范围内 cohort 后续是否转化、留存或复购；默认取当前数据刷新时间；如果页面单独传入观察截止时间，则取页面传入时间和当前数据刷新时间中更早的时间 |
| 体验课 | 是教学链漏斗环节，不算正式成交 |
| 订场 | 只要是真实有效付费或有效权益消耗，就算成交 |
| 订场会员 | 属于订场链最终转化，不单独拆成第三条会员链 |
| 总成交 | 只做去重汇总，不是一条漏斗 |
| 复购 | 只在同一业务链内计算，不跨教学链和订场链混算 |
| 留存 | 看成交后是否继续使用或继续消费，不等于复购 |

## 5. 转化漏斗口径

### 5.1 转化结构

FlowTennis 只保留两条业务转化链和一个总成交汇总。

```text
教学链：线索 → 预约体验课 → 已体验 → 正式课包
订场链：线索 → 首次订场 → 订场会员
总成交：线索 → 任一正式付费成交
```

总成交不是漏斗，只是去重汇总。

### 5.2.1 预约体验课证据优先级

预约体验课人数只能按下列优先级取一次结果，不得把多个数据源相加。

| 优先级 | 判断证据 | 命中条件 | 预约时间 |
|---|---|---|---|
| 1 | 体验课排课记录 | 有体验课类型排课记录，且状态不是已取消、测试 | 排课开始时间 |
| 2 | 体验课预约记录 | 有独立体验课预约记录，且状态不是已取消、测试 | 预约时间 |
| 3 | 体验课课包购买记录 | 有有效体验课课包购买记录，订单未退款、未作废、非测试 | 购买时间 |
| 4 | 线索阶段 | 线索阶段进入过“已约体验” | 首次进入“已约体验”的时间 |

执行规则：

1. 同一客户同时命中多个证据时，只取最高优先级证据。
2. 同一客户在同一优先级有多条证据时，取最早一条有效证据。
3. 只在备注、沟通记录或聊天内容里写“想体验”，但没有上表任何证据，不算预约体验课。
4. 取消后没有重新预约成功，不算预约体验课。

### 5.3.1 转化率时间归属规则

转化率统一采用线索 cohort 口径，不采用当期事件口径。

| 规则 | 定义 |
|---|---|
| cohort 人群 | 线索进入时间落在统计范围内的有效线索客户 |
| 分母 | 只从 cohort 人群里取 |
| 分子 | 只从 cohort 人群里取，且对应转化动作发生时间必须晚于或等于线索进入时间，并且不晚于统计截止时间 |
| 阶段顺序 | 教学链必须按线索 → 预约体验课 → 已体验 → 正式课包；订场链必须按线索 → 首次订场 → 订场会员 |
| 跨期转化 | 线索在本期进入，转化动作在本期之后但不晚于统计截止时间，计入该线索 cohort 的转化 |
| 当期事件 | 只看统计范围内发生的预约、到课、成交事件，不等于转化率口径 |

执行示例：

```text
统计范围：6月1日-6月30日
统计截止时间：7月15日
客户 A：6月10日进入线索池，7月5日买正式课包
客户 A 计入 6月线索 cohort 的课程转化率分子。
```

## 6. 留存与复购口径

### 6.1 留存结构

```text
教学留存：正式课包后是否续买 / 持续上课
订场留存：首次订场后是否再次订场 / 持续订场
```

留存看成交后是否继续使用或继续消费。复购只看同一业务链内是否发生第二次及以上有效购买。

### 6.3 复购率时间归属规则

复购率统一采用首购 cohort 口径，不采用当期复购事件口径。

| 指标 | 分母 | 分子 |
|---|---|---|
| 课包复购率 | 统计范围内首次购买正式课包的客户人数 | 分母客户中，首次购买之后、统计截止时间前发生第二次及以上正式课包购买的人数 |
| 订场复订率 | 统计范围内首次发生有效订场的客户人数 | 分母客户中，首次订场之后、统计截止时间前发生第二次及以上有效订场的人数 |
| 订场会员再次储值率 | 统计范围内首次有效储值成为订场会员的客户人数 | 分母客户中，首次储值之后、统计截止时间前发生第二次及以上有效储值的人数 |
| 总复购率 | 统计范围内首次成为总成交的客户人数 | 分母客户中，首次成交之后、统计截止时间前发生课包复购或订场会员再次储值的人数；第二次及以上订场不计入总复购 |

执行规则：

1. 第三次、第四次购买不增加复购人数，只影响复购次数和复购金额。
2. 跨链购买不算复购。
3. 统计范围只决定分母 cohort；分子动作可以发生在统计范围之后，但不能晚于统计截止时间。
4. 第二次及以上订场属于订场复订或订场持续消费，不属于总复购率分子。

### 6.4 课包续购窗口

| 续购窗口条件 | 进入窗口时间 |
|---|---|
| 剩余课时 | 有效消课后，课包剩余课时首次 <= 2 的核销时间 |
| 已消耗完 | 有效消课后，课包剩余课时首次 = 0 的核销时间 |
| 到期窗口 | 课包到期日前 30 天的 00:00 |

执行规则：

1. 满足任一条件，即进入课包续购窗口。
2. 同一个课包只取最早一次进入窗口时间。
3. 分母统计时间口径：统计范围内首次进入续购窗口的客户人数，按进入窗口时间归属统计范围。
4. 如果同一客户有多个正式课包在统计范围内进入续购窗口，分母只算 1 人，取最早进入窗口的课包作为本次续购判断对象。
5. 有课包到期日时，续购窗口结束时间 = 课包到期日后 30 天的 23:59:59。
6. 没有课包到期日时，续购窗口结束时间 = 进入窗口时间后 30 天的 23:59:59。
7. 分子只统计购买时间大于或等于进入窗口时间，且小于或等于续购窗口结束时间的正式课包购买客户。
8. 如果续购购买时间早于进入窗口时间，或晚于续购窗口结束时间，不计入本次续购。

### 6.5 N 日留存观察期

| 指标 | N 的固定取值 | 默认展示 |
|---|---|---|
| N 日订场持续消费率 | 7 / 30 / 60 / 90 / 120 / 360 | 30 日 |
| N 日订场会员留存率 | 30 / 60 / 90 | 30 日 |

执行规则：

1. N 只能使用上表固定取值。
2. 如果页面只展示一个值，必须展示默认值。
3. 如果页面提供切换，只能在上表固定取值中切换。
4. 分母只包含已完整度过 N 天观察期的客户。
5. 观察期是否完整的判断：起点事件时间 + N 天 <= 统计截止时间。
6. 订场持续消费的起点事件是首次有效订场；分子事件必须是同一客户的第二次及以上有效订场，且订场开始时间大于首次有效订场开始时间。
7. 订场会员留存的起点事件是首次有效储值；分子事件必须是同一客户首次有效储值后的有效订场，包含余额扣款订场、单独支付订场、会员权益抵扣订场。
8. 如果只有日期没有时分秒，起点当天发生的第二条及以上有效订场记录计入 N 日观察期；同一条订场记录不能同时作为起点和分子。

### 6.6 不算复购的情况

| 行为 | 是否复购 | 原因 |
|---|---|---|
| 先买课包，后订场 | 否 | 两条链路分别转化，不是同链复购 |
| 先订场，后买课包 | 否 | 两条链路分别转化，不是同链复购 |
| 先订场，后储值订场会员 | 否 | 这是订场链升级，不是复购 |
| 储值后继续订场 | 否 | 对订场会员来说是留存，不是再次储值 |
| 买第三个正式课包 | 不增加复购人数 | 已在第二次购买时计为复购人，第三次只增加次数和金额 |

### 11.2 场地利用率

| 口径 ID | 指标名 | 公式 | 业务解释 | 当前状态 |
|---|---|---|---|---|
| COURT_UTILIZATION_RATE | 场地利用率 | 已使用场时 / 可用场时 | 看可经营场地时间里有多少被真实使用 | 已固化 |
| COURT_DAILY_UTILIZATION_RATE | 当日场地利用率 | 当日已使用场时 / 当日可用场时 | 看某一天场地使用情况 | 已固化 |
| COURT_RANGE_UTILIZATION_RATE | 选定范围场地利用率 | 选定范围内已使用场时 / 选定范围内可用场时 | 看本周、本月或自定义时间范围内的场地使用情况 | 已固化 |
| COURT_BUSINESS_UTILIZATION_RATE | 经营利用率 | 经营场时 / 可用场时 | 看可经营场地时间里有多少产生经营价值 | 已固化 |

计算规则：

1. 当日可用场时 = 当日启用场地数量 × 当日可经营小时数。
2. 本周可用场时 = 本周每天可用场时相加，不直接假设每天都一样。
3. 本月可用场时 = 本月每天可用场时相加。
4. 自定义范围可用场时 = 用户选择的每一天可用场时相加。
5. 若某天有维修、临时关闭、内部占用或不可用时段，必须先从当天可用场时中扣除。
6. 计算最小单位必须用分钟，页面展示再换算成小时，避免跨小时记录误差。

例子：

```text
1 片场，当日可经营 10 小时，已使用 2 小时
当日场地利用率 = 2 / 10 = 20%

4 片场，当日每片可经营 10 小时，已使用 8 小时
当日可用场时 = 4 × 10 = 40
当日场地利用率 = 8 / 40 = 20%

4 片场，连续 7 天，每天每片可经营 10 小时，已使用 80 小时
本周可用场时 = 4 × 10 × 7 = 280
本周场地利用率 = 80 / 280 = 28.57%
```

线索归属校区规则：

1. 优先取线索表里的所属校区。
2. 如果线索没有校区，取创建人当前校区。
3. 不因为后续消费发生在别的校区而自动修改。

客户主校区判断优先级：

```text
人工指定客户主校区 > 最近一次有效消费校区 > 最近一次已完成上课校区 > 线索归属校区
```

客户主校区规则：

1. 客户主校区按判断优先级动态变化。
2. 客户主校区变化影响客户当前归属统计。
3. 客户主校区变化不反向修改历史订单、历史排课、历史订场的发生校区。
4. 最近一次有效消费包括正式课包购买、有效订场、订场会员储值。
5. 如果同一客户同一时间有多笔有效消费，按业务记录创建时间最晚的一笔确定；创建时间仍相同，按记录 ID 字典序最大的记录确定。

消费发生校区规则：

1. 课包购买发生校区 = 购买记录归属校区。
2. 排课上课校区 = 排课记录里的上课校区。
3. 订场发生校区 = 订场记录里的场地所属校区。
4. 订场会员储值发生校区 = 会员订单或储值记录归属校区。
5. 财务中心和经营分析中的收入、消耗、订场、课包购买、储值指标必须按消费发生校区统计。

教练课时量补充规则：

1. 私教课、体验课、小班课、大师课等课程类型计入课时量。
2. 陪打不计入课时量。
3. 课时量按课程实际时长折算，不按课程条数简单计数。
4. 一节课 60 分钟计 1 课时；90 分钟计 1.5 课时；120 分钟计 2 课时。
5. 小班课、团课、多人课不按学员人数倍增课时；一节 60 分钟小班课仍计 1 课时。
6. 一节课记录多个上课教练时，每名上课教练各计完整课时，不做平分。
7. 课时量不是比例指标，没有分子和分母；实现时直接汇总有效课程时长。

教练体验课转化率补充规则：

1. 分母按体验课上课教练计算。
2. 分子按正式课包成交教练计算。
3. 只有同一个客户的体验课上课教练和正式课包成交教练都是同一教练时，才计入该教练体验课转化率分子。
4. 不设置 30 天、60 天等成交时间窗口。
5. 体验课完成后任意时间购买正式课包，只要购买时间满足第 9、10 条，且成交教练一致，就计入分子。
6. 同一客户在同一教练名下完成多次体验课，分母只算 1 人，取该教练名下最早一次已完成体验课作为判断时间。
7. 同一客户在多个教练名下分别完成体验课，分别进入对应上课教练的分母。
8. 同一客户购买多个正式课包，分子只算 1 人，取购买时间最早且成交教练一致的正式课包作为判断依据。
9. 如果体验课完成时间和正式课包购买时间只有日期没有时分秒，同一自然日完成体验并购买正式课包，计入分子。
10. 如果有具体时分秒，正式课包购买时间必须大于体验课完成时间；购买时间早于或等于体验课完成时间，不计入分子。

课后反馈完成率补充规则：

1. 有效课次数按排课记录计数，不按学员人数计数。
2. 小班课、团课、多人课的一条排课记录只算 1 个需反馈课次。
3. 一节课记录多个上课教练时，该课对每名上课教练各形成 1 个需反馈课次。
4. 当前排课记录已有有效课后反馈，即视为该课对所有上课教练反馈完成。
5. 有效课后反馈 = 反馈记录已提交，未删除，未作废，且关联到该排课记录。
6. 是否需要课后反馈以课程类型配置为准；课程类型未配置“需要课后反馈”时，该课程不进入分母。

教案提交率补充规则：

1. 需教案课次数按排课记录计数，不按学员人数计数。
2. 小班课、团课、多人课的一条排课记录只算 1 个需教案课次。
3. 一节课记录多个上课教练时，该课对每名上课教练各形成 1 个需教案课次。
4. 当前排课记录已有有效教案或教练提案，即视为该课对所有上课教练教案已提交。
5. 有效教案或教练提案 = 教案记录或教练提案记录已提交，未删除，未作废，且关联到该排课记录。
6. 是否需要教案或教练提案以课程类型配置为准；课程类型未配置“需要教案”或“需要教练提案”时，该课程不进入分母。
7. 教案按时提交率的按时判断：有效教案或教练提案的提交时间必须小于或等于课程开始时间。

课包续购补充规则：

1. 教练课包续购率只按课包归属教练归因。
2. 不按上课教练归因。
3. 不按成交教练归因。
4. 一个客户在续购窗口内多次购买正式课包，续购人数只算 1 人。
5. 归因对象是进入续购窗口的原课包归属教练；续购新课包的课包归属教练不改变本次续购率归因。
6. 同一客户在同一统计范围内有多个课包分别归属不同教练并进入续购窗口时，该客户可分别进入不同教练的分母；同一教练名下只算 1 人。
7. 同一客户在同一教练名下有多个课包进入续购窗口时，取该教练名下最早进入续购窗口的课包作为判断对象。
