## 2. 写死的入口规则

### 2.1 管理端 Web

- 真实入口只有 `flowtennis-mgmt-main/public/index.html`
- 访问 `/` 后进入统一登录页
- 管理员账号登录后，默认首页固定是 `students`

### 2.2 教练端网页

- 真实入口也是 `flowtennis-mgmt-main/public/index.html`
- 访问 `/` 后进入统一登录页
- 教练账号登录后，默认首页固定是 `workbench`

### 2.3 教练端 PWA

- 真实入口仍然是 `flowtennis-mgmt-main/public/index.html`
- 安装壳来自：
  - `flowtennis-mgmt-main/public/manifest.webmanifest`
  - `flowtennis-mgmt-main/public/service-worker.js`
- `start_url` 固定 `/`
- 教练账号进入后，默认首页固定是 `workbench`

### 2.4 教练端小程序

- 真实入口只有 `flowtennis-mgmt-main/wechat-miniprogram/miniprogram/app.json`
- 教练入口固定是 `pages/index/index`
- 这是教练端小程序壳，不是当前正式用户约球入口

### 2.5 约球小程序

- 当前真实入口在 `flowtennis-mini-match/miniprogram/app.json`
- 当前默认首页固定是 `pages/matches/index`
- `flowtennis-mgmt-main/wechat-miniprogram/miniprogram/pages/profile/index` 不是当前约球正式验收首页
- 教练入口 `pages/index/index` 不能作为约球默认首页

---

## 3. AppID 与发布载体固化

### 3.1 管理端 Web / 教练端网页 / 教练端 PWA

- 同属一个 Web 发布载体：`https://www.flowtennis.cn`
- 同属 `flowtennis-mgmt-main` 仓库前端壳
- 区分方式不是换目录，而是：
  - 登录身份
  - 默认页
  - PWA 是否安装

### 3.2 教练端小程序

- 真实 AppID 固定为：`wx7acb7603ee803923`
- 真实工程固定为：`flowtennis-mgmt-main/wechat-miniprogram`
- 教练登录入口固定走：`pages/index/index`
- 当前角色是教练端小程序壳，不是当前约球验收对象

### 3.3 约球小程序

- 当前真实 AppID 固定为：`wxec5ca996f273502b`
- 当前真实工程固定为：`flowtennis-mini-match`
- 当前默认首页固定为：`pages/matches/index`
- 当前正式用户约球入口固定就是这套独立工程
- `flowtennis-mgmt-main/wechat-miniprogram` 不是当前约球正式验收载体

- `_local/*` 下内容默认都不是正式线上载体。
- `flowtennis-mini-match/` 当前是正式约球验收载体，不属于历史遗留，也不是备用工程。

## 5. 后续线程必须遵守的硬规则

1. 当前真实约球小程序载体只能认 `flowtennis-mini-match`。
2. 当前真实约球小程序默认首页只能认 `pages/matches/index`。
3. 教练端入口 `pages/index/index` 不能作为约球默认首页。
4. 教练端网页、教练端 PWA、管理端 Web 虽然共用 `flowtennis-mgmt-main/public`，但它们不是“一个端”，汇报时必须按 3 个端分别说明影响。
5. 教练端小程序真实载体只能认 `flowtennis-mgmt-main/wechat-miniprogram`。
6. `flowtennis-mini-match` 当前就是正式约球验收载体，不能再降级写成备用工程。
7. 新线程不得自行猜测“小程序真实载体”“默认首页”“AppID”；必须先以本文档和 `AGENTS.md` 为准。
8. 任何新需求如果触达“约球”字样，必须先判断目标到底是：
   - 管理端里的约球管理页
   - `flowtennis-mini-match` 正式用户约球入口
   - `flowtennis-mgmt-main/wechat-miniprogram` 教练端小程序壳
   不能把这 3 类目标混成一个。

## 6. 最短判断法

如果是下面这些目标，直接去对应目录：

- 后台管理、学员、排课、财务、约球管理页：`flowtennis-mgmt-main/public`
- 教练网页、教练 PWA：`flowtennis-mgmt-main/public`
- 教练微信小程序：`flowtennis-mgmt-main/wechat-miniprogram/miniprogram` 的 `pages/index/index`
- 当前真实约球小程序：`flowtennis-mini-match/miniprogram` 的 `pages/matches/index`
- `flowtennis-mgmt-main/wechat-miniprogram/miniprogram/pages/profile/index`：不是当前约球正式验收首页

如果有人只说“改小程序”但没说是哪一个，不能开工，必须先按本表核对目标端。
