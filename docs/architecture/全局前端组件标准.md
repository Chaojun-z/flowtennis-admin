## 硬规则

新增页面必须使用 standard/ 里的全局组件入口。

禁止在非订场业务里继续调用旧入口：

- 禁止 `setCourtModalFrame` 作为通用弹窗入口。
- 禁止 `openDetailSideDrawer` 作为通用抽屉入口。
- `setCourtModalFrame`
- `openDetailSideDrawer`
- `renderCourtTopDropdown`
- `courtTopLocationIcon`
- `courtTopTimeIcon`
- `courtTopCoachIcon`
- `closeCourtTopDropdowns`
- `toggleCourtTopDropdown`

## 当前标准入口

- 弹窗：`openStandardModal`
- 抽屉：`openStandardDetailDrawer`
- 顶部筛选：`renderStandardTopDropdown`
- 表格空值、分页、筛选：`renderStandard...`

## 订场业务例外

`courts.js` 里只允许保留真正描述订场业务的 `renderCourt...` 函数，例如订场用户、订场财务、订场日期范围、订场流水等业务函数。

通用 UI 不能再用 `Court` 命名。
