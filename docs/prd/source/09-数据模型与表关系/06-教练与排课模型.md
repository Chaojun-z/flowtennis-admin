## 1. 模型目标

教练与排课模型保证后台排课、教练端工作台、教练小程序日程、课程详情、课后反馈、教练统计读取同一套课程事实。

| 原则 | 说明 |
|---|---|
| 排课是课程事实 | `ft_schedule` 是课程发生、状态、教练、学员、场地的核心记录。 |
| 教练只看授权范围 | 教练端 Web/小程序只能看本人课程和本人关联学员。 |
| 反馈绑定课程 | 课后评价必须绑定具体排课记录。 |
| 统计不重算口径 | 教练课时、人效、反馈完成率读取统一指标模型。 |
| 权益消耗可追溯 | 排课消课必须能追溯权益账户和权益流水。 |

## 2. 核心表和对象

| 对象 | 表/来源 | 定位 |
|---|---|---|
| 教练 | `ft_coaches` | 教练基础资料、状态、归属校区。 |
| 后台账号 | `ft_users` | 管理端/教练端登录账号和角色。 |
| 微信绑定 | `ft_user_wechat_index` | 教练小程序 openid 与账号/教练绑定。 |
| 学员 | `ft_students` | 上课对象。 |
| 排课 | `ft_schedule` | 课程事实主表。 |
| 反馈 | `ft_feedbacks` | 课后评价、训练建议、转化建议。 |
| 权益账户 | `ft_entitlements` | 可扣课余额。 |
| 权益流水 | `ft_entitlement_ledger` | 消课凭证。 |
| 班次 | `ft_classes` | 历史兼容班次。 |
| 教练排课索引 | `ft_coach_schedule_index` | 教练端读取优化索引。 |

## 3. 教练字段

| 字段 | 含义 | 规则 |
|---|---|---|
| `id` | 教练 ID | 全局唯一。 |
| `name` | 教练姓名 | 排课、统计、教练端展示使用。 |
| `phone` | 手机号 | 可用于账号绑定和联系。 |
| `campusScope` | 归属校区 | 多校区权限和排课筛选使用。 |
| `status` | 状态 | active、inactive、hidden 等。 |
| `userId` | 关联后台账号 | 教练登录和权限使用。 |
| `openid` | 微信绑定 | 小程序登录后识别教练。 |

## 4. 排课字段

| 字段 | 含义 | 规则 |
|---|---|---|
| `id` | 排课 ID | 全局唯一。 |
| `studentId` | 学员 ID | 必须能回到客户生命周期。 |
| `coachId`/`coachName` | 上课教练 | 必须对应教练资料。 |
| `campus` | 上课校区 | 业务发生校区。 |
| `courtName`/`venue` | 场地 | 有场地时必须展示。 |
| `courseType` | 课程类型 | 统一课程类型字典。 |
| `businessType` | 业务类型 | 体验课、私教、小班等。 |
| `startTime`/`endTime` | 上课时间 | 冲突校验、日历、提醒都使用。 |
| `status` | 排课状态 | scheduled、completed、cancelled 等。 |
| `entitlementId` | 扣课权益 | 消课时必须有。 |
| `feedbackId` | 反馈 | 反馈提交后关联。 |
| `sourceType` | 来源 | 后台排课、班次生成、导入等。 |

## 5. 反馈字段

| 字段 | 含义 | 规则 |
|---|---|---|
| `id` | 反馈 ID | 全局唯一。 |
| `scheduleId` | 排课 ID | 必填。 |
| `coachId` | 教练 ID | 只能提交本人课程反馈，管理员除外。 |
| `studentId` | 学员 ID | 与排课一致。 |
| `lessonSummary` | 课堂总结 | 教练填写。 |
| `trainingAdvice` | 训练建议 | 学员/运营可读。 |
| `conversionIntent` | 转化意向 | 运营跟进参考。 |
| `operationSuggestion` | 运营建议 | 回写后台客户/线索跟进。 |
| `submittedAt` | 提交时间 | 反馈完成率统计。 |
| `status` | 状态 | draft、submitted、voided 等。 |

## 6. 状态规则

| 对象 | 状态 | 进入条件 | 影响 |
|---|---|---|---|
| 排课 | scheduled | 已创建未完成 | 教练端日程可见。 |
| 排课 | completed | 已上课/确认完成 | 可触发消课、入账、待反馈。 |
| 排课 | cancelled | 已取消 | 不计完成课时，权益按规则返还/不扣。 |
| 排课 | no_show | 缺课 | 是否扣课按业务规则。 |
| 反馈 | draft | 暂存 | 不计反馈完成。 |
| 反馈 | submitted | 已提交 | 计入反馈完成率，后台可见。 |
| 教练 | active | 正常 | 可排课、可登录。 |
| 教练 | inactive | 停用 | 不可新增排课，不可登录教练端。 |

## 7. 写入链路

| 动作 | 必须写入 | 必须校验 |
|---|---|---|
| 新增排课 | `ft_schedule` | 学员、教练、校区、时间、权益可用、冲突。 |
| 编辑排课 | `ft_schedule` | 已完成课程变更需保护权益和财务。 |
| 取消排课 | 排课状态、必要的权益回滚/记录 | 不能删除历史。 |
| 完成课程 | 排课状态、权益流水、财务入账 | 权益可扣、金额可追溯。 |
| 提交反馈 | `ft_feedbacks`、排课反馈状态 | 只能本人或授权角色提交。 |
| 教练绑定微信 | `ft_user_wechat_index`/账号绑定 | openid 不能绑定多个冲突教练。 |

## 8. 教练端读取规则

| 端 | 读取范围 | 写入范围 |
|---|---|---|
| 教练端 Web 工作台 | 本人今日/本周课程、待反馈、教案待办 | 跳转反馈、查看课程。 |
| 教练端 Web 课后评价 | 本人课程 | 提交/更新本人课程反馈。 |
| 教练端 Web 我的学员 | 本人排课/班次/反馈关联学员 | 只读为主。 |
| 教练端 Web 我的班次 | 本人班次和进度 | 只读。 |
| 教练小程序首页 | 登录绑定、今日课程、待办 | 微信绑定。 |
| 教练小程序排课日程 | 本人课程日程 | 只读。 |
| 教练小程序课程详情 | 本人单节课 | 提交/查看反馈。 |

## 9. 页面影响范围

| 页面 | 使用内容 |
|---|---|
| 排课管理 | 新增、编辑、取消、完成、权益推荐。 |
| 排课日历 | 按日/周/月展示课程。 |
| 教练课时统计 | 课时量、工作量、反馈完成率。 |
| 教练端 Web | 工作台、反馈、我的学员、我的班次。 |
| 教练小程序 | 首页、日程、课程详情。 |
| 经营分析教练人效 | 课时、转化、续费、反馈、教案。 |

## 10. 验收清单

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| CS-01 | 后台新增排课 | 教练 Web 和小程序本人日程可见。 |
| CS-02 | 教练提交反馈 | 后台排课详情、学员详情、教练统计同步变化。 |
| CS-03 | 完成课程消课 | 权益余额减少，权益流水和财务入账可追溯。 |
| CS-04 | 教练权限 | A 教练不能看到 B 教练课程。 |
| CS-05 | 取消课程 | 不计完成课时，权益/财务按规则处理。 |
| CS-06 | 教练停用 | 不可新增排课，不可继续登录教练端。 |
