## 1. 页面目标

分析场地使用、经营场时、订场收入、有效订场、黄金时段和非黄金时段利用率。

## 2. 使用角色

- 管理员
- 运营人员

## 3. 页面入口

| 项 | 内容 |
|---|---|
| 端 | 管理后台 |
| 一级模块 | 经营分析 |
| 页面名称 | 场地运转 |
| 页面 ID / 面板 | operations / court |
| 菜单路径 | 管理后台 / 经营分析 / 场地运转 |

## 4. 功能范围

### 4.1 必须支持

- 查看已使用场时、经营场时、有效订场、订场收入
- 查看场地利用率、黄金利用率、非黄金利用率
- 按时间、校区、场地、时段筛选
- 查看时段分布和渠道分布
- 与订场用户和财务场地收入交叉核对

### 4.2 不在本页处理

- 不改变统一数据口径
- 不绕过权限和安全规则
- 不直接改写其他模块事实数据

## 5. 页面结构

| 区域 | 内容 | 复现要求 |
|---|---|---|
| 顶部摘要 | 关键数量、金额、状态或风险 | 说明全局/筛选/页面视图口径 |
| 筛选工具栏 | 搜索、日期、校区、状态、类型 | 筛选后列表、导出、统计同步 |
| 主内容 | 表格、看板、图表或卡片 | 空状态、失败态、分页固定 |
| 详情/弹窗 | 查看或维护单条记录 | 字段和列表同源 |
| 导出/审计 | CSV、流水、快照或历史 | 导出列与页面字段一致 |

## 6. 字段清单

| 区域 | 字段 / 指标 | 来源 / 口径 | 展示或编辑规则 |
|---|---|---|---|
| 卡片 | 已使用场时 COURT_USED_HOURS | 订场/排课事实 | 统一场地口径 |
| 卡片 | 经营场时 COURT_BUSINESS_HOURS | 校区营业场时配置 | 分母口径固定 |
| 卡片 | 订场收入 FIN_COURT_INCOME | 财务统一层 | 与财务总览一致 |
| 卡片 | 有效订场 COURT_VALID_BOOKING | 订场读模型 | 取消/无效不计 |
| 卡片 | 场地利用率、黄金/非黄金利用率 | COURT_UTILIZATION_RATE 等 | 分时段计算 |

## 7. 筛选、搜索与排序

| 能力 | 字段 | 规则 |
|---|---|---|
| 日期 | 统计周期 | 按业务发生时间 |
| 枚举 | 校区、场地、时段 | 统一校区和场地配置 |
| 渠道 | 来源/订场类型 | 如有展示必须统一字典 |

## 8. 核心操作规则

| 操作 | 触发入口 | 业务规则 | 结果影响 |
|---|---|---|---|
| 切换周期/校区 | 筛选栏 | 重算场地指标 | 卡片和图表同步 |
| 查看来源 | 图表点击 | 定位订场用户或财务流水 | 完成追溯 |

## 9. 状态与流转规则

| 对象 | 状态 | 进入条件 | 退出或禁止条件 |
|---|---|---|---|
| 订场 | 有效 | 完成或确认的订场 | 取消/作废退出 |
| 时段 | 黄金/非黄金 | 按配置规则 | 配置变化只影响新统计口径说明 |

## 10. 数据关系

| 财务到场地分析 | financePage | 场地收入 | 财务总览 |

## 12. 权限规则

| 角色 | 可见范围 | 可操作范围 |
|---|---|---|
| 管理员 | 全量或按配置范围 | 可新增、编辑、作废、导出 |
| 运营人员 | 按校区和数据权限 | 处理授权业务 |
| 财务角色 | 财务和审计数据 | 核对/导出，写入受高风险规则约束 |

## 13. 异常场景

| 场景 | 页面表现 | 处理规则 |
|---|---|---|
| 无数据 | 业务空状态 | 不显示技术错误 |
| 接口失败 | 提示重试 | 不得半写入 |
| 权限不足 | 无权限提示 | 不得暴露越权数据 |
| 口径冲突 | 提示需查口径文档 | 不得页面临时重算 |
| 历史数据 | 按兼容规则展示 | 不扩散旧字段 |

## 14. 验收标准

- 订场收入和财务总览场地收入一致
- 有效订场和订场用户有效记录一致
- 黄金/非黄金利用率分母清楚
- 取消订场不进入有效订场
- 按校区筛选后分母和分子同步变化

## 15. 复刻级补充要求

本节是本页面交付给研发、测试或 AI 复刻时的硬性检查项。复刻“场地运转”时，不能只实现菜单入口或静态页面，必须把本页字段、操作、状态、接口、权限、异常和验收闭环全部落地。

### 15.1 页面区域完整性

| 区域 | 复刻要求 | 不合格表现 |
|---|---|---|
| 页面入口 | 必须按第 3 节入口、页面 ID、菜单路径接入。 | 只有菜单但不能打开，或打开后不是本页数据。 |
| 顶部摘要 | 必须实现第 5/6 节定义的卡片或摘要，并说明全局、筛选、当前视图口径。 | 卡片数字和列表/经营分析不一致。 |
| 筛选搜索 | 必须实现第 7 节列出的搜索、日期、枚举、校区等筛选，并同步影响列表和导出。 | 筛选只改列表，不改统计或导出。 |
| 主列表/看板 | 必须实现第 6 节列表字段，空状态、加载失败、分页/排序规则可用。 | 字段缺失、字段名不统一、展示原始 ID 或原始时间。 |
| 详情/弹窗 | 必须和列表同源，展示第 6 节详情字段和第 8 节操作结果。 | 列表和详情同一字段显示不同口径。 |
| 导入导出/审计 | 本页有导入、导出、流水、历史时，必须与页面字段和权限一致。 | 导出列多于或少于 PRD，或导出绕过权限。 |

### 15.2 字段落地规则

| 类型 | 必须落实 |
|---|---|
| 展示字段 | 第 6 节出现的字段必须全部可见或有明确空状态，不得用旧字段名替代。 |
| 编辑字段 | 可编辑字段必须有默认值、必填规则、格式规则、保存后回显规则。 |
| 状态字段 | 第 9 节状态必须有进入条件、退出条件、禁止操作。 |
| 金额/课时/次数 | 必须引用 05 数据口径和 09 数据模型，不得页面本地重算核心口径。 |
| 日期时间 | 列表展示日期用统一格式，详情需要精确时间时再展示分钟级时间。 |
| 内部字段 | 记录 ID、流水 ID、调试字段、导入批次默认不展示给业务用户，除非本页明确是审计页。 |

### 15.3 操作契约

| 操作类型 | 复刻要求 |
|---|---|
| 新增/编辑 | 必须按第 8 节校验输入、保存事实表、刷新列表和详情。 |
| 删除/作废 | 默认优先作废或隐藏，不得物理删除影响财务、权益、排课、会员的历史事实。 |
| 转化/关联 | 必须保留来源关系，例如线索、学员、订场、会员之间的关联键。 |
| 导入 | 必须先预览校验，再提交；失败行不写入；结果要可追溯。 |
| 导出 | 导出列必须和本页字段清单一致，并服从当前筛选和账号权限。 |
| 高风险写入 | 涉及财务、权益、会员、订场、排课完成时，必须同时满足 10 和 11 的安全/验收规则。 |

### 15.4 数据与接口契约

| 项 | 要求 |
|---|---|
| 数据来源 | 第 11 节列出的接口/读模型是本页默认来源；不得另起页面私有口径。 |
| 页面缓存 | 保存、作废、导入、转化后必须刷新本页和受影响页面的数据。 |
| 跨页一致 | 本页字段如出现在财务、经营分析、客户生命周期、教练端，必须和对应页面同源。 |
| 兼容数据 | 历史字段只允许映射到标准字段，不得继续作为新字段展示。 |
| 空值处理 | 空值必须显示业务可理解的空状态，不得显示 undefined、null、NaN。 |

### 15.5 权限与异常

| 场景 | 要求 |
|---|---|
| 管理员 | 可见和可操作范围按 01 角色权限执行。 |
| 校区权限 | 受校区范围限制的账号只能看授权校区数据。 |
| 教练权限 | 教练只能看本人课程、本人学员、本人反馈。 |
| 接口失败 | 页面提示重试，不产生半条业务记录。 |
| 权限不足 | 不展示越权数据，操作入口不可用或提交失败并提示。 |
| 数据冲突 | 重复手机号、重复报名、余额不足、排课冲突等必须提示冲突原因。 |

### 15.6 AI 可执行验收

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| PAGE-01 | 打开页面 | 能通过第 3 节入口打开“场地运转”，页面标题和数据域正确。 |
| PAGE-02 | 字段完整 | 第 6 节字段在列表、详情、导出或审计入口中按定义出现。 |
| PAGE-03 | 筛选一致 | 第 7 节筛选后，列表、顶部摘要、导出结果一致。 |
| PAGE-04 | 操作闭环 | 第 8 节每个操作执行后，相关页面和读模型数据同步。 |
| PAGE-05 | 状态正确 | 第 9 节状态流转符合进入/退出/禁止条件。 |
| PAGE-06 | 权限隔离 | 不同角色、不同校区、教练本人范围按第 12 节隔离。 |
| PAGE-07 | 异常可控 | 第 13 节异常不产生脏数据，不暴露内部错误。 |
| PAGE-08 | PRD 自包含 | 复刻本页不需要打开 PRD 目录以外的旧 docs 文档。 |
