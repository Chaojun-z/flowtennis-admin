## 1. 页面目标

维护后台和教练端登录账号、角色、数据范围、校区权限、教练绑定和微信/服务号绑定状态。

## 2. 使用角色

- 管理员
- 运营人员

## 3. 页面入口

| 项 | 内容 |
|---|---|
| 端 | 管理后台 |
| 一级模块 | 系统设置 |
| 页面名称 | 账号管理 |
| 页面 ID / 面板 | admin-users |
| 菜单路径 | 管理后台 / 系统设置 / 账号管理 |

## 4. 功能范围

### 4.1 必须支持

- 查看账号列表
- 新增、编辑、停用账号
- 重置密码
- 设置管理员/运营/教练角色
- 设置数据范围和可见校区
- 绑定教练身份
- 清除教练小程序微信绑定
- 清除服务号绑定
- 配置约球管理权限

### 4.2 不在本页处理

- 不改变统一数据口径
- 不绕过权限和安全规则
- 不直接改写其他模块事实数据

## 5. 页面结构

| 区域 | 内容 | 复现要求 |
|---|---|---|
| 顶部摘要 | 关键数量、状态或待办 | 说明口径和刷新条件 |
| 筛选工具栏 | 搜索、日期、校区、状态等 | 筛选后列表和统计同步 |
| 主内容 | 表格、卡片、日程、列表或表单 | 空状态、失败态、分页固定 |
| 详情/弹窗 | 查看或维护单条记录 | 字段和列表同源 |
| 审计/协议 | 日志、绑定、协议或通知记录 | 可追溯 |

## 6. 字段清单

| 区域 | 字段 / 指标 | 来源 / 口径 | 展示或编辑规则 |
|---|---|---|---|
| 列表/表单 | 账号姓名、手机号/账号 | adminUsers | 登录和展示 |
| 表单 | 角色 | admin/editor 等 | 决定后台/教练视角 |
| 表单 | 关联教练 | coachId/coachName | 教练端本人数据依据 |
| 表单 | 数据范围、可见校区 | dataScope/campusIds | 权限过滤 |
| 表单 | 状态 | active/inactive | 停用不能登录 |
| 绑定 | 微信绑定、服务号绑定 | openid/officialAccount fields | 可清除重新绑定 |
| 权限 | 约球权限 | matchPermissions | 约球后台操作范围 |

## 7. 筛选、搜索与排序

| 能力 | 字段 | 规则 |
|---|---|---|
| 搜索 | 姓名、账号、手机号、教练 | 模糊搜索 |
| 角色 | 管理员/运营/教练 | 账号角色 |
| 状态 | 启用/停用 | 登录状态 |

## 8. 核心操作规则

| 操作 | 触发入口 | 业务规则 | 结果影响 |
|---|---|---|---|
| 新增账号 | 新增按钮 | 账号、密码、角色必填；教练角色需绑定教练 | 生成登录账号 |
| 编辑账号 | 编辑按钮 | 修改角色、教练、校区权限、状态 | 影响登录和数据范围 |
| 重置密码 | 重置按钮 | 新密码写入哈希，不展示明文 | 用户重新登录 |
| 停用账号 | 状态按钮 | 停用后禁止登录 | 保留审计 |
| 清除绑定 | 绑定操作 | 清除微信或服务号绑定 | 用户可重新绑定 |

## 9. 状态与流转规则

| 对象 | 状态 | 进入条件 | 退出或禁止条件 |
|---|---|---|---|
| 账号 | 启用 | 可登录 | 停用后退出 |
| 账号 | 停用 | 禁止登录 | 启用后恢复 |
| 微信绑定 | 已绑定 | openid 绑定账号 | 清除后需账号密码重新绑定 |
| 教练身份 | 已关联 | 绑定 coachId | 可进入教练视角 |

## 10. 数据关系

| 关系 | 上游 | 本页使用 | 下游影响 |
|---|---|---|---|
| 账号到教练 | adminUsers.coachId | 本人数据范围 | 教练端 Web/小程序 |
| 账号到权限 | role/dataScope/campusIds | 后台可见范围 | 所有页面 |
| 账号到微信 | openid | 小程序快捷登录 | 教练小程序 |

## 11. 接口与数据来源

| 用途 | 接口 / 读模型 | 方法 | 说明 |
|---|---|---|---|
| 读取账号 | /admin/users | GET | 账号列表 |
| 新增账号 | /admin/create-user | POST | 创建账号 |
| 编辑账号 | /admin/update-user | POST | 更新角色、权限、绑定 |
| 重置密码 | /admin/reset-user-password | POST | 重置密码 |
| 登录 | /auth/login、/auth/wechat-login、/auth/wechat-bind | POST | 账号和微信登录 |

## 12. 权限规则

| 角色 | 可见范围 | 可操作范围 |
|---|---|---|
| 管理员 | 全量或按配置范围 | 可新增、编辑、停用、导出 |
| 运营人员 | 按校区和数据权限 | 处理授权业务 |
| 教练 | 仅本人数据 | 只能查看/提交本人相关内容 |

## 13. 异常场景

| 场景 | 页面表现 | 处理规则 |
|---|---|---|
| 无数据 | 业务空状态 | 不显示技术错误 |
| 接口失败 | 提示重试 | 不得半写入 |
| 权限不足 | 无权限提示 | 不得暴露越权数据 |
| 绑定缺失 | 提示完成绑定 | 不自动冒用身份 |
| 历史数据 | 按兼容规则展示 | 不扩散旧字段 |

## 14. 验收标准

- 停用账号不能登录
- 教练账号绑定教练后只看本人课程
- 校区权限限制后台数据范围
- 清除微信绑定后微信快捷登录失败并提示先绑定
- 重置密码不在页面或文档暴露明文旧密码

## 15. 复刻级补充要求

本节是本页面交付给研发、测试或 AI 复刻时的硬性检查项。复刻“账号管理”时，不能只实现菜单入口或静态页面，必须把本页字段、操作、状态、接口、权限、异常和验收闭环全部落地。

### 15.1 页面区域完整性

| 区域 | 复刻要求 | 不合格表现 |
|---|---|---|
| 页面入口 | 必须按第 3 节入口、页面 ID、菜单路径接入。 | 只有菜单但不能打开，或打开后不是本页数据。 |
| 顶部摘要 | 必须实现第 5/6 节定义的卡片或摘要，并说明全局、筛选、当前视图口径。 | 卡片数字和列表/经营分析不一致。 |
| 筛选搜索 | 必须实现第 7 节列出的搜索、日期、枚举、校区等筛选，并同步影响列表和导出。 | 筛选只改列表，不改统计或导出。 |
| 主列表/看板 | 必须实现第 6 节列表字段，空状态、加载失败、分页/排序规则可用。 | 字段缺失、字段名不统一、展示原始 ID 或原始时间。 |
| 详情/弹窗 | 必须和列表同源，展示第 6 节详情字段和第 8 节操作结果。 | 列表和详情同一字段显示不同口径。 |
| 导入导出/审计 | 本页有导入、导出、流水、历史时，必须与页面字段和权限一致。 | 导出列多于或少于 PRD，或导出绕过权限。 |

### 15.2 字段落地规则

| 类型 | 必须落实 |
|---|---|
| 展示字段 | 第 6 节出现的字段必须全部可见或有明确空状态，不得用旧字段名替代。 |
| 编辑字段 | 可编辑字段必须有默认值、必填规则、格式规则、保存后回显规则。 |
| 状态字段 | 第 9 节状态必须有进入条件、退出条件、禁止操作。 |
| 金额/课时/次数 | 必须引用 05 数据口径和 09 数据模型，不得页面本地重算核心口径。 |
| 日期时间 | 列表展示日期用统一格式，详情需要精确时间时再展示分钟级时间。 |
| 内部字段 | 记录 ID、流水 ID、调试字段、导入批次默认不展示给业务用户，除非本页明确是审计页。 |

### 15.3 操作契约

| 操作类型 | 复刻要求 |
|---|---|
| 新增/编辑 | 必须按第 8 节校验输入、保存事实表、刷新列表和详情。 |
| 删除/作废 | 默认优先作废或隐藏，不得物理删除影响财务、权益、排课、会员的历史事实。 |
| 转化/关联 | 必须保留来源关系，例如线索、学员、订场、会员之间的关联键。 |
| 导入 | 必须先预览校验，再提交；失败行不写入；结果要可追溯。 |
| 导出 | 导出列必须和本页字段清单一致，并服从当前筛选和账号权限。 |
| 高风险写入 | 涉及财务、权益、会员、订场、排课完成时，必须同时满足 10 和 11 的安全/验收规则。 |

### 15.4 数据与接口契约

| 项 | 要求 |
|---|---|
| 数据来源 | 第 11 节列出的接口/读模型是本页默认来源；不得另起页面私有口径。 |
| 页面缓存 | 保存、作废、导入、转化后必须刷新本页和受影响页面的数据。 |
| 跨页一致 | 本页字段如出现在财务、经营分析、客户生命周期、教练端，必须和对应页面同源。 |
| 兼容数据 | 历史字段只允许映射到标准字段，不得继续作为新字段展示。 |
| 空值处理 | 空值必须显示业务可理解的空状态，不得显示 undefined、null、NaN。 |

### 15.5 权限与异常

| 场景 | 要求 |
|---|---|
| 管理员 | 可见和可操作范围按 01 角色权限执行。 |
| 校区权限 | 受校区范围限制的账号只能看授权校区数据。 |
| 教练权限 | 教练只能看本人课程、本人学员、本人反馈。 |
| 接口失败 | 页面提示重试，不产生半条业务记录。 |
| 权限不足 | 不展示越权数据，操作入口不可用或提交失败并提示。 |
| 数据冲突 | 重复手机号、重复报名、余额不足、排课冲突等必须提示冲突原因。 |

| PAGE-06 | 权限隔离 | 不同角色、不同校区、教练本人范围按第 12 节隔离。 |
