## 1. 页面目标

审计每一次会员开卡、续充、充值记录，保留方案快照、充值金额、赠送权益、折扣、有效期和作废原因。

## 2. 使用角色

- 管理员
- 运营人员

## 3. 页面入口

| 项 | 内容 |
|---|---|
| 端 | 管理后台 |
| 一级模块 | 场地会员 |
| 页面名称 | 会员购买记录 |
| 页面 ID / 面板 | membership-orders |
| 菜单路径 | 管理后台 / 场地会员 / 会员管理 / 会员购买记录 |

## 4. 功能范围

### 4.1 必须支持

- 查看会员购买记录审计列表
- 搜索客户、手机号、方案
- 按日期、状态、方案筛选
- 查看系统金额、实收金额、赠送金额、折扣、权益摘要
- 作废会员订单
- 追溯订单对应会员账户和权益流水

### 4.2 不在本页处理

- 不改变跨模块统一数据口径
- 不绕过权限和财务安全规则
- 不直接改写其他模块事实数据

## 5. 页面结构

| 区域 | 内容 | 复现要求 |
|---|---|---|
| 顶部摘要 | 展示本页关键数量、金额、状态或风险 | 卡片必须标注口径范围 |
| 筛选工具栏 | 搜索、日期、校区、状态、类型等筛选 | 筛选后列表、导出、统计同步 |
| 主列表 / 看板 | 展示核心记录 | 字段、空状态、加载失败、分页固定 |
| 详情 / 抽屉 / 弹窗 | 查看或维护单条记录 | 详情字段和列表同口径 |
| 导入 / 导出 / 审计 | 按需要提供 CSV、流水或历史 | 导出列与页面字段一致 |

## 6. 字段清单

| 区域 | 字段 / 指标 | 来源 / 口径 | 展示或编辑规则 |
|---|---|---|---|
| 列表 | 购买日期、创建时间 | purchaseDate / createdAt | 购买和审计时间分开展示 |
| 列表 | 客户、手机号、会员方案 | courtName / phone / membershipPlanName | 快照字段 |
| 列表 | 系统金额、实收金额、赠送金额 | systemAmount/finalAmount/bonusAmount | 财务核对 |
| 列表 | 折扣、是否重置有效期 | discountRate / qualifiesRenewalReset | 会员周期规则 |
| 列表 | 权益摘要 | benefitSnapshot | 展示本单赠送权益 |
| 列表 | 状态、作废原因 | status / voidReason | 审计作废 |

## 7. 筛选、搜索与排序

| 能力 | 字段 | 规则 |
|---|---|---|
| 搜索 | 姓名、手机号、方案 | 模糊搜索 |
| 日期 | 购买日期、创建时间 | 可按业务或审计时间 |
| 枚举 | 状态、方案、校区 | 与会员账户关联 |

## 8. 核心操作规则

| 操作 | 触发入口 | 业务规则 | 结果影响 |
|---|---|---|---|
| 查看记录 | 列表行 | 展开订单快照和权益摘要 | 不改写事实 |
| 作废订单 | 作废按钮 | 已有财务和权益影响时必须走作废流程，不物理删除 | 账户、财务、权益同步审计 |
| 导出 | 导出按钮 | 导出当前筛选订单 | 用于财务核对 |

## 9. 状态与流转规则

| 对象 | 状态 | 进入条件 | 退出或禁止条件 |
|---|---|---|---|
| 订单 | 有效 | 购买成功 | 作废后退出 |
| 订单 | 已作废 | 人工作废并写原因 | 保留历史 |
| 权益快照 | 已固化 | 购买时复制方案 | 不随方案修改变化 |

## 10. 数据关系

| 关系 | 上游 | 本页使用 | 下游影响 |
|---|---|---|---|
| 订单到账户 | membership_orders | 账户状态和周期依据 | 会员管理 |
| 订单到财务 | membership_orders + courts.history | 储值收入 | 财务总览、收款流水 |
| 订单到权益 | benefitSnapshot | 权益发放来源 | 会员权益流水 |

## 11. 接口与数据来源

| 用途 | 接口 / 读模型 | 方法 | 说明 |
|---|---|---|---|
| 读取订单 | /membership-orders | GET | 会员订单列表 |
| 新增订单 | /membership-orders | POST | 会员管理开卡/续充调用 |
| 编辑/作废 | /membership-orders/:id | PUT / DELETE | 审计修改或作废 |
| 读取账户 | /membership-accounts | GET | 关联账户 |

## 12. 权限规则

| 角色 | 可见范围 | 可操作范围 |
|---|---|---|
| 管理员 | 全量或按配置数据范围 | 可新增、编辑、删除/作废、导入导出 |
| 运营人员 | 按账号校区和数据权限 | 可处理授权范围内业务 |
| 财务角色 | 财务相关页面和流水 | 可查看/核对财务，写入受高风险规则约束 |

## 13. 异常场景

| 场景 | 页面表现 | 处理规则 |
|---|---|---|
| 无数据 | 展示业务空状态 | 不显示技术错误 |
| 接口失败 | 提示重试 | 不得半写入 |
| 权限不足 | 展示无权限 | 不得暴露越权数据 |
| 历史兼容数据 | 按兼容规则展示 | 不得扩散成新口径 |
| 重复或冲突 | 提示冲突原因 | 不静默覆盖 |

## 14. 验收标准

- 每次会员开卡都生成一条会员购买记录
- 订单金额和财务收款流水一致
- 方案修改不影响历史订单快照
- 作废订单保留原因和时间
- 权益摘要和会员权益流水能对上

## 15. 复刻级补充要求

本节是本页面交付给研发、测试或 AI 复刻时的硬性检查项。复刻“会员购买记录”时，不能只实现菜单入口或静态页面，必须把本页字段、操作、状态、接口、权限、异常和验收闭环全部落地。

### 15.1 页面区域完整性

| 区域 | 复刻要求 | 不合格表现 |
|---|---|---|
| 页面入口 | 必须按第 3 节入口、页面 ID、菜单路径接入。 | 只有菜单但不能打开，或打开后不是本页数据。 |
| 顶部摘要 | 必须实现第 5/6 节定义的卡片或摘要，并说明全局、筛选、当前视图口径。 | 卡片数字和列表/经营分析不一致。 |
| 筛选搜索 | 必须实现第 7 节列出的搜索、日期、枚举、校区等筛选，并同步影响列表和导出。 | 筛选只改列表，不改统计或导出。 |
| 主列表/看板 | 必须实现第 6 节列表字段，空状态、加载失败、分页/排序规则可用。 | 字段缺失、字段名不统一、展示原始 ID 或原始时间。 |
| 详情/弹窗 | 必须和列表同源，展示第 6 节详情字段和第 8 节操作结果。 | 列表和详情同一字段显示不同口径。 |
| 导入导出/审计 | 本页有导入、导出、流水、历史时，必须与页面字段和权限一致。 | 导出列多于或少于 PRD，或导出绕过权限。 |

### 15.2 字段落地规则

| 类型 | 必须落实 |
|---|---|
| 展示字段 | 第 6 节出现的字段必须全部可见或有明确空状态，不得用旧字段名替代。 |
| 编辑字段 | 可编辑字段必须有默认值、必填规则、格式规则、保存后回显规则。 |
| 状态字段 | 第 9 节状态必须有进入条件、退出条件、禁止操作。 |
| 金额/课时/次数 | 必须引用 05 数据口径和 09 数据模型，不得页面本地重算核心口径。 |
| 日期时间 | 列表展示日期用统一格式，详情需要精确时间时再展示分钟级时间。 |
| 内部字段 | 记录 ID、流水 ID、调试字段、导入批次默认不展示给业务用户，除非本页明确是审计页。 |

### 15.3 操作契约

| 操作类型 | 复刻要求 |
|---|---|
| 新增/编辑 | 必须按第 8 节校验输入、保存事实表、刷新列表和详情。 |
| 删除/作废 | 默认优先作废或隐藏，不得物理删除影响财务、权益、排课、会员的历史事实。 |
| 转化/关联 | 必须保留来源关系，例如线索、学员、订场、会员之间的关联键。 |
| 导入 | 必须先预览校验，再提交；失败行不写入；结果要可追溯。 |
| 导出 | 导出列必须和本页字段清单一致，并服从当前筛选和账号权限。 |
| 高风险写入 | 涉及财务、权益、会员、订场、排课完成时，必须同时满足 10 和 11 的安全/验收规则。 |

### 15.4 数据与接口契约

| 项 | 要求 |
|---|---|
| 数据来源 | 第 11 节列出的接口/读模型是本页默认来源；不得另起页面私有口径。 |
| 页面缓存 | 保存、作废、导入、转化后必须刷新本页和受影响页面的数据。 |
| 跨页一致 | 本页字段如出现在财务、经营分析、客户生命周期、教练端，必须和对应页面同源。 |
| 兼容数据 | 历史字段只允许映射到标准字段，不得继续作为新字段展示。 |
| 空值处理 | 空值必须显示业务可理解的空状态，不得显示 undefined、null、NaN。 |

### 15.5 权限与异常

| 场景 | 要求 |
|---|---|
| 管理员 | 可见和可操作范围按 01 角色权限执行。 |
| 校区权限 | 受校区范围限制的账号只能看授权校区数据。 |
| 教练权限 | 教练只能看本人课程、本人学员、本人反馈。 |
| 接口失败 | 页面提示重试，不产生半条业务记录。 |
| 权限不足 | 不展示越权数据，操作入口不可用或提交失败并提示。 |
| 数据冲突 | 重复手机号、重复报名、余额不足、排课冲突等必须提示冲突原因。 |

### 15.6 AI 可执行验收

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| PAGE-01 | 打开页面 | 能通过第 3 节入口打开“会员购买记录”，页面标题和数据域正确。 |
| PAGE-02 | 字段完整 | 第 6 节字段在列表、详情、导出或审计入口中按定义出现。 |
| PAGE-03 | 筛选一致 | 第 7 节筛选后，列表、顶部摘要、导出结果一致。 |
| PAGE-04 | 操作闭环 | 第 8 节每个操作执行后，相关页面和读模型数据同步。 |
| PAGE-05 | 状态正确 | 第 9 节状态流转符合进入/退出/禁止条件。 |
| PAGE-06 | 权限隔离 | 不同角色、不同校区、教练本人范围按第 12 节隔离。 |
| PAGE-07 | 异常可控 | 第 13 节异常不产生脏数据，不暴露内部错误。 |
| PAGE-08 | PRD 自包含 | 复刻本页不需要打开 PRD 目录以外的旧 docs 文档。 |
