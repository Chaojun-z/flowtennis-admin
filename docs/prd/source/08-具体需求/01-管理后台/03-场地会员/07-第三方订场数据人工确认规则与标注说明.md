# 第三方订场数据人工确认规则与标注说明

> 适用范围：第三方 `2026-07-01` 至 `2026-07-15` 第一批数据清洗  
> 当前状态：只读预检阶段，不导入、不写入 FlowTennis  
> 目标：把不能自动判断的数据交给运营按统一规则标注，标注完成后再进入导入预检

---

## 1. 人工确认的原因

第三方后台里有一类数据叫“锁场”。锁场不等于订场，也不等于排课。

锁场可能是：

1. 私教课排课占场。
2. 内部使用，例如清洗、维修、训练。
3. 运营替会员订场，扣会员余额。
4. 运营替散客订场，散客微信转账给运营。
5. 运营替散客订场，散客用大众点评券码或其他平台券。
6. 教练自己订场，例如 `晓哲 定场`，教练 8 折微信转账给运营。
7. 畅打、陪打、活动占场。

因此不能把所有锁场直接导入为订场收入。

## 3. 可自动处理的数据

以下数据不需要运营逐条确认：

| 数据 | 自动处理规则 |
|---|---|
| 手机号匹配到 FlowTennis 订场用户 | 合并到现有订场用户 |

| 清洗、维修、打扫 | 自动归为内部占用，不计收入 |

## 5. 最终业务类型选项

运营只能从以下固定选项中选择，不能自由填写新类型。

| 最终业务类型 | 适用场景 | 财务处理 | 场地占用处理 |
|---|---|---|---|
| 排课占场 | 私教课、体验课、课程排课 | 不新增场地收入 | 绑定 FlowTennis 排课，不重复占用 |
| 内部占用 | 清洗、维修、内部训练、领导使用 | 不计收入 | 计内部占用 |
| 会员余额订场 | 运营替会员订场并扣会员余额 | 已入账增加，待履约减少，总收入不变 | 计会员订场占用 |
| 散客微信转账订场 | 散客微信转账给运营 | 计场地收入 | 计散客订场占用 |
| 散客现金订场 | 散客现金付款 | 计场地收入 | 计散客订场占用 |
| 大众点评券码订场 | 大众点评券码、团购券、核销码 | 按确认结算金额计收入 | 计散客订场占用 |
| 教练代订场 | 教练自己订场，通常 8 折微信转账给运营 | 按确认金额计场地收入 | 计订场占用 |
| 畅打活动 | 畅打、4 人畅打、活动占场 | 看是否已有活动收款 | 计活动占用 |
| 订场陪打 | 订场 + 陪打 | 按确认金额和业务归属处理 | 计占用 |
| 忽略不导入 | 测试、误锁、无效记录 | 不计收入 | 不计占用 |
| 待老板确认 | 运营无法判断 | 暂不入账 | 暂不确认占用 |

| 支付方式 | 说明 |
|---|---|
| 会员余额 | 从会员储值余额扣款 |
| 微信转账 | 用户或教练转账给运营 |
| 现金 | 现金收款 |
| 大众点评券码 | 大众点评券码、团购券、核销码 |
| 其他平台券码 | 抖音、美团或其他平台券 |
| 已在活动中收款 | 畅打或活动已经在其他记录里收款 |
| 不涉及支付 | 内部占用、排课占场、忽略不导入 |

## 7. 各类备注的处理规则

| 第三方备注特征 | 系统建议分类 | 是否自动 | 运营需要做什么 |
|---|---|---|---|
| `私教课`、`体验课`、`上课`，且姓名能匹配排课 | 排课占场 | 自动 | 不需要处理 |
| `私教课`、`体验课`、`上课`，但只匹配到时间场地 | 排课占场低置信 | 人工确认 | 确认是否绑定该排课 |
| `私教课`、`体验课`、`上课`，但没找到排课 | 排课占场未匹配 | 人工确认 | 判断是漏排课还是备注错误 |
| `清洗场地`、`打扫`、`维修` | 内部占用 | 自动 | 不需要处理 |
| `训练` | 备注不清 | 人工确认 | 判断是内部训练、课程还是活动 |
| 空备注 | 备注为空 | 人工确认 | 必须选择最终业务类型 |
| `晓哲 定场`、教练名 + `定场/订场` | 教练代订场 | 人工确认 | 确认金额和支付方式 |
| 普通人名 + `定场/订场` | 运营代订场 | 人工确认 | 判断会员余额、微信转账、现金或券码 |
| `畅打`、`4人畅打` | 畅打活动 | 人工确认 | 确认是否已有活动收款 |
| `陪打` | 订场陪打 | 人工确认 | 确认收入归属和金额 |
| `大众点评`、`券`、`团购`、`核销` | 第三方券码订场 | 人工确认 | 填写券码来源和结算金额 |

## 8. 人工确认后的导入规则

人工确认完成后，系统按以下规则进入下一轮预检。

| 运营标注结果 | 后续处理 |
|---|---|
| 排课占场 | 只绑定排课，不新增订场收入 |
| 内部占用 | 写入内部场地占用，不计收入 |
| 会员余额订场 | 扣会员余额，已入账增加，待履约减少，总收入不变 |
| 散客微信/现金订场 | 写入订场记录，计场地收入 |
| 大众点评券码订场 | 按确认结算金额写入订场收入 |
| 教练代订场 | 按确认金额写入场地收入，支付方式为微信转账/现金等 |
| 畅打活动 | 如果已有活动收款，只计占用；如果未收款，按确认金额计收入 |
| 订场陪打 | 按确认规则拆分订场收入和陪打收入 |
| 忽略不导入 | 不写业务表，不影响财务 |
| 待老板确认 | 暂停导入 |
