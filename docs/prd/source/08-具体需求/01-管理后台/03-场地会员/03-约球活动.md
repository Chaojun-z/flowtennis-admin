## 1. 页面目标

管理约球活动、报名名单、订场确认、到场确认、退出换人和费用结算边界，承接约球小程序和后台运营视角。

## 2. 使用角色

- 管理员
- 运营人员

## 3. 页面入口

| 项 | 内容 |
|---|---|
| 端 | 管理后台 |
| 一级模块 | 场地会员 |
| 页面名称 | 约球活动 |
| 页面 ID / 面板 | matches |
| 菜单路径 | 管理后台 / 场地会员 / 约球活动 |

## 4. 功能范围

### 4.1 必须支持

- 查看全部约球活动
- 按状态、时间、校区筛选
- 查看活动详情、报名名单、费用拆分
- 确认订场信息和场地费
- 取消活动
- 确认到场
- 处理报名退出和换人
- 确认费用和单人支付状态
- 查看约球财务日报

### 4.2 不在本页处理

- 不改变跨模块统一数据口径
- 不绕过权限和财务安全规则
- 不直接改写其他模块事实数据

## 5. 页面结构

| 区域 | 内容 | 复现要求 |
|---|---|---|
| 顶部摘要 | 展示本页关键数量、金额、状态或风险 | 卡片必须标注口径范围 |
| 筛选工具栏 | 搜索、日期、校区、状态、类型等筛选 | 筛选后列表、导出、统计同步 |
| 主列表 / 看板 | 展示核心记录 | 字段、空状态、加载失败、分页固定 |
| 详情 / 抽屉 / 弹窗 | 查看或维护单条记录 | 详情字段和列表同口径 |
| 导入 / 导出 / 审计 | 按需要提供 CSV、流水或历史 | 导出列与页面字段一致 |

## 6. 字段清单

| 区域 | 字段 / 指标 | 来源 / 口径 | 展示或编辑规则 |
|---|---|---|---|
| 列表/详情 | 活动名称、活动时间、场地 | matches | 约球活动主信息 |
| 列表/详情 | 报名人数、候补人数、人数上限 | registrations | 按状态实时计算 |
| 列表/详情 | 活动状态 MATCH_STATUS_OPTIONS | match status | 招募中、已成局、已取消、已结算等 |
| 详情 | 报名人、支付状态、到场状态 | registrations / fee_splits | 每人独立可审计 |
| 详情 | 场地费、AA金额、费用确认 | finance fields | 费用结算边界 |

## 7. 筛选、搜索与排序

| 能力 | 字段 | 规则 |
|---|---|---|
| 搜索 | 活动名称、用户姓名、手机号 | 模糊搜索 |
| 枚举 | 活动状态、校区、费用状态 | 约球字典 |
| 日期 | 活动开始时间 | 按活动时间筛选 |

## 8. 核心操作规则

| 操作 | 触发入口 | 业务规则 | 结果影响 |
|---|---|---|---|
| 确认订场 | 订场按钮 | 填写最终场馆、场号、场地费、订场状态 | 活动进入已订场/待到场 |
| 取消活动 | 取消按钮 | 填写原因 | 通知和状态变化 |
| 确认到场 | 到场按钮 | 按报名人记录到场状态 | 影响费用承担 |
| 退出处理 | 报名人操作 | 设置责任方和原因 | 影响退款或费用责任 |
| 换人 | 替补/换人操作 | 填写替补手机号、支付状态、说明 | 报名关系迁移 |
| 费用确认 | 确认费用按钮 | 锁定 AA 费用拆分 | 费用进入待收/已收 |

## 9. 状态与流转规则

| 对象 | 状态 | 进入条件 | 退出或禁止条件 |
|---|---|---|---|
| 活动 | 招募中 | 创建后开放报名 | 人数达标或运营确认后变化 |
| 活动 | 已订场 | 后台确认订场 | 活动完成或取消后退出 |
| 活动 | 已取消 | 运营或规则取消 | 保留历史和责任记录 |
| 费用 | 待确认 | 活动未结算 | 确认后生成费用拆分 |
| 费用 | 已结清 | 所有费用完成 | 异常退款或补款需单独记录 |

## 10. 数据关系

| 关系 | 上游 | 本页使用 | 下游影响 |
|---|---|---|---|
| 小程序到后台 | match_users / matches | 活动、报名、我的约球 | 约球小程序 |
| 约球到财务 | match fee splits | 费用结算 | 财务日报/经营分析边界 |
| 约球到订场 | 后台确认订场 | 场地占用信息 | 订场用户/场地运转边界 |

## 11. 接口与数据来源

| 用途 | 接口 / 读模型 | 方法 | 说明 |
|---|---|---|---|
| 后台列表 | /admin/matches | GET | 后台活动列表 |
| 订场确认 | /admin/matches/:id/booking | POST | 最终订场信息 |
| 取消活动 | /admin/matches/:id/cancel | POST | 取消原因 |
| 到场确认 | /admin/matches/:id/attendance | POST | 批量到场状态 |
| 退出/换人 | /admin/matches/:id/registrations/:userId/withdrawal、/replacements/transfer | POST | 处理报名变更 |
| 费用 | /admin/matches/:id/fees/confirm、/fees/splits/:userId | POST | 费用确认和支付状态 |

## 12. 权限规则

| 角色 | 可见范围 | 可操作范围 |
|---|---|---|
| 管理员 | 全量或按配置数据范围 | 可新增、编辑、删除/作废、导入导出 |
| 运营人员 | 按账号校区和数据权限 | 可处理授权范围内业务 |
| 财务角色 | 财务相关页面和流水 | 可查看/核对财务，写入受高风险规则约束 |

## 13. 异常场景

| 场景 | 页面表现 | 处理规则 |
|---|---|---|
| 无数据 | 展示业务空状态 | 不显示技术错误 |
| 接口失败 | 提示重试 | 不得半写入 |
| 权限不足 | 展示无权限 | 不得暴露越权数据 |
| 历史兼容数据 | 按兼容规则展示 | 不得扩散成新口径 |
| 重复或冲突 | 提示冲突原因 | 不静默覆盖 |

## 14. 验收标准

- 小程序报名后后台报名名单同步出现
- 后台取消活动后小程序活动状态同步变化
- 到场确认和费用拆分能追溯到每个报名人
- 换人后原用户和替补用户责任清楚
- 约球费用不污染教学排课和课包消课模型

## 15. 复刻级补充要求

本节是本页面交付给研发、测试或 AI 复刻时的硬性检查项。复刻“约球活动”时，不能只实现菜单入口或静态页面，必须把本页字段、操作、状态、接口、权限、异常和验收闭环全部落地。

### 15.1 页面区域完整性

| 区域 | 复刻要求 | 不合格表现 |
|---|---|---|
| 页面入口 | 必须按第 3 节入口、页面 ID、菜单路径接入。 | 只有菜单但不能打开，或打开后不是本页数据。 |
| 顶部摘要 | 必须实现第 5/6 节定义的卡片或摘要，并说明全局、筛选、当前视图口径。 | 卡片数字和列表/经营分析不一致。 |
| 筛选搜索 | 必须实现第 7 节列出的搜索、日期、枚举、校区等筛选，并同步影响列表和导出。 | 筛选只改列表，不改统计或导出。 |
| 主列表/看板 | 必须实现第 6 节列表字段，空状态、加载失败、分页/排序规则可用。 | 字段缺失、字段名不统一、展示原始 ID 或原始时间。 |
| 详情/弹窗 | 必须和列表同源，展示第 6 节详情字段和第 8 节操作结果。 | 列表和详情同一字段显示不同口径。 |
| 导入导出/审计 | 本页有导入、导出、流水、历史时，必须与页面字段和权限一致。 | 导出列多于或少于 PRD，或导出绕过权限。 |

### 15.2 字段落地规则

| 类型 | 必须落实 |
|---|---|
| 展示字段 | 第 6 节出现的字段必须全部可见或有明确空状态，不得用旧字段名替代。 |
| 编辑字段 | 可编辑字段必须有默认值、必填规则、格式规则、保存后回显规则。 |
| 状态字段 | 第 9 节状态必须有进入条件、退出条件、禁止操作。 |
| 金额/课时/次数 | 必须引用 05 数据口径和 09 数据模型，不得页面本地重算核心口径。 |
| 日期时间 | 列表展示日期用统一格式，详情需要精确时间时再展示分钟级时间。 |
| 内部字段 | 记录 ID、流水 ID、调试字段、导入批次默认不展示给业务用户，除非本页明确是审计页。 |

### 15.3 操作契约

| 操作类型 | 复刻要求 |
|---|---|
| 新增/编辑 | 必须按第 8 节校验输入、保存事实表、刷新列表和详情。 |
| 删除/作废 | 默认优先作废或隐藏，不得物理删除影响财务、权益、排课、会员的历史事实。 |
| 转化/关联 | 必须保留来源关系，例如线索、学员、订场、会员之间的关联键。 |
| 导入 | 必须先预览校验，再提交；失败行不写入；结果要可追溯。 |
| 导出 | 导出列必须和本页字段清单一致，并服从当前筛选和账号权限。 |
| 高风险写入 | 涉及财务、权益、会员、订场、排课完成时，必须同时满足 10 和 11 的安全/验收规则。 |

### 15.4 数据与接口契约

| 项 | 要求 |
|---|---|
| 数据来源 | 第 11 节列出的接口/读模型是本页默认来源；不得另起页面私有口径。 |
| 页面缓存 | 保存、作废、导入、转化后必须刷新本页和受影响页面的数据。 |
| 跨页一致 | 本页字段如出现在财务、经营分析、客户生命周期、教练端，必须和对应页面同源。 |
| 兼容数据 | 历史字段只允许映射到标准字段，不得继续作为新字段展示。 |
| 空值处理 | 空值必须显示业务可理解的空状态，不得显示 undefined、null、NaN。 |

### 15.5 权限与异常

| 场景 | 要求 |
|---|---|
| 管理员 | 可见和可操作范围按 01 角色权限执行。 |
| 校区权限 | 受校区范围限制的账号只能看授权校区数据。 |
| 教练权限 | 教练只能看本人课程、本人学员、本人反馈。 |
| 接口失败 | 页面提示重试，不产生半条业务记录。 |
| 权限不足 | 不展示越权数据，操作入口不可用或提交失败并提示。 |
| 数据冲突 | 重复手机号、重复报名、余额不足、排课冲突等必须提示冲突原因。 |
