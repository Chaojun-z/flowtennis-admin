## 1. 页面目标

展示当前仍有运营价值的学员。口径包含课包有余额的学员、近 90 天仍有正式课记录的学员，以及长期单次付费学员；不再只按“买过正式课包”判断。

## 2. 使用角色

- 管理员
- 运营人员

## 3. 页面入口

| 项 | 内容 |
|---|---|
| 端 | 管理后台 |
| 一级模块 | 客户与线索 |
| 页面名称 | 在期学员 |
| 页面 ID / 面板 | package-students |
| 菜单路径 | 管理后台 / 客户与线索 / 在期学员 |

## 4. 功能范围

### 4.1 必须支持

- 查看在期学员列表和详情
- 查看课包订单、权益列表、上课记录
- 购买课包
- 手动新增或消耗权益
- 设置服务号提醒
- 按校区、来源、类型、负责教练和标签级联筛选；标签级联包含课包状态、付费方式、活跃状态、累计上课、学员状态

### 4.2 不在本页处理

- 不改变统一数据口径
- 不绕过权限和安全规则
- 不直接改写其他模块事实数据

## 5. 页面结构

| 区域 | 内容 | 复现要求 |
|---|---|---|
| 顶部摘要 | 关键数量、金额、状态或待办 | 说明全局/筛选/页面视图口径 |
| 筛选工具栏 | 搜索、日期、校区、类型、来源、负责教练、标签级联筛选 | 筛选后列表、导出、统计同步 |
| 主列表 / 看板 | 展示核心记录 | 字段、空状态、失败态、分页固定 |
| 详情 / 抽屉 / 弹窗 | 查看或维护单条记录 | 字段和列表同源 |
| 导入 / 导出 / 审计 | 按需提供 CSV、流水或历史 | 导出列与页面字段一致 |

## 6. 字段清单

| 区域 | 字段 / 指标 | 来源 / 口径 | 展示或编辑规则 |
|---|---|---|---|
| 顶部卡片 | 在期学员、近30天正式课活跃、近90天正式课活跃、课包有余额、课包即将耗尽 | 学员活跃与标签体系 | 用于判断当前仍有运营价值的人 |
| 列表/详情 | 姓名、类型、来源、校区、负责教练、备注 | customerLifecycle / teachingStudentViews | 和历史学员同字段口径 |
| 列表 | 活跃状态、付费方式、课包状态、课包余额、最近上课、累计上课、累计课程付费、学员状态 | STUDENT_ACTIVITY_STATUS / STUDENT_PAYMENT_MODE / STUDENT_PACKAGE_STATUS / teachingStudentViews.packageBalanceText / teachingStudentViews.detailRecentLessonDate / CUSTOMER_TOTAL_ATTENDED_LESSONS / CUSTOMER_CUMULATIVE_COURSE_PAID_AMOUNT / STUDENT_LIFECYCLE_STATUS | 使用统一标签，保留课包余额列，不再展示旧购买时间列；历史课时不单独成列 |
| 详情 | 课包订单、上课记录、权益流水 | purchases / schedule / entitlementLedger | 可审计 |

## 7. 筛选、搜索与排序

| 能力 | 字段 | 规则 |
|---|---|---|
| 搜索 | 姓名、手机号、来源、备注、订场账户、负责教练 | 模糊搜索 |
| 常用筛选 | 校区、来源、类型、负责教练 | 作为常驻筛选入口 |
| 标签级联筛选 | 课包状态、付费方式、活跃状态、累计上课、学员状态 | 一级为标签组，二级为标签值；支持多选、选项人数、清空和单项移除；同组内为或，跨组为且；累计上课支持 30+ / 50+ / 100+ |
| 日期 | 全局日期筛选 | 使用页面统一日期范围组件 |

## 8. 核心操作规则

| 操作 | 触发入口 | 业务规则 | 结果影响 |
|---|---|---|---|
| 购买课包 | 详情购买按钮 | 选择学员、课包、金额、支付方式 | 生成购买、权益、财务 |
| 新增权益 | 权益面板 | 必须选择来源和原因 | 写权益流水 |
| 消耗权益 | 权益面板 | 不得扣成负数 | 更新剩余课时 |
| 编辑学员 | 详情编辑 | 改名手机号需联动展示 | 保持历史链路 |

## 9. 状态与流转规则

| 对象 | 状态 | 进入条件 | 退出或禁止条件 |
|---|---|---|---|
| 在期学员 | 进入在期学员 | 历史学员的子集；课包有余额，或近90天有正式课；未取消且时间已过去的已排课正式课计入最近正式课 | 超过90天无正式课且无课包余额后退出在期列表 |
| 课包状态 | 未买过课包 / 课包有余额 / 课包即将耗尽 / 课包已用完 | 只针对正式课包 | 单次付费学员不能误判为课包已用完 |
| 付费方式 | 课包学员 / 单次付费学员 / 课包+单次付费 | 按后端统一标签判断；`课包`、`课包划扣`、`课包核销` 等都属于课包方式 | 资源置换和零元正式课归入单次付费 |
| 学员状态 | 已转单次付费 / 有余额未活跃 | 用于运营判断下一步动作 | 不再使用“待续费”“稳定单次付费”等容易误解的汇总标签 |

## 10. 数据关系

| 关系 | 上游 | 本页使用 | 下游影响 |
|---|---|---|---|
| 购买到学员 | purchases | 正式身份依据 | 正式学员/经营分析 |
| 权益到账 | entitlements | 余额和规则 | 排课管理 |
| 上课记录 | schedule + ledger | 累计上课和消耗 | 教练统计/财务 |
| 学员标签 | teachingStudentViews | 后端统一输出列表范围、活跃状态、付费方式、课包状态、累计上课筛选、学员状态、最近上课、累计课程付费 | 前端只展示和筛选，不得重新计算 |

## 12. 权限规则

| 角色 | 可见范围 | 可操作范围 |
|---|---|---|
| 管理员 | 全量或按配置范围 | 可新增、编辑、删除/作废、导入导出 |
| 运营人员 | 按账号校区和数据权限 | 可处理授权范围业务 |
| 财务角色 | 财务相关页面和流水 | 可核对财务，写入受高风险规则约束 |

## 13. 异常场景

| 场景 | 页面表现 | 处理规则 |
|---|---|---|
| 无数据 | 展示业务空状态 | 不显示技术错误 |
| 接口失败 | 提示重试 | 不得产生半条记录 |
| 权限不足 | 提示无权限 | 不得暴露越权数据 |
| 重复或冲突 | 提示冲突原因 | 不静默覆盖 |
| 历史兼容数据 | 按兼容规则展示 | 不扩散旧字段 |

## 14. 验收标准

- 购买课包后正式学员出现
- 剩余课时和权益账户一致
- 上课记录与排课一致
- 作废购买后权益和财务同步变化
- 改名手机号后相关页面展示同步

## 15. 复刻级补充要求

本节是本页面交付给研发、测试或 AI 复刻时的硬性检查项。复刻“正式学员”时，不能只实现菜单入口或静态页面，必须把本页字段、操作、状态、接口、权限、异常和验收闭环全部落地。

### 15.1 页面区域完整性

| 区域 | 复刻要求 | 不合格表现 |
|---|---|---|
| 页面入口 | 必须按第 3 节入口、页面 ID、菜单路径接入。 | 只有菜单但不能打开，或打开后不是本页数据。 |
| 顶部摘要 | 必须实现第 5/6 节定义的卡片或摘要，并说明全局、筛选、当前视图口径。 | 卡片数字和列表/经营分析不一致。 |
| 筛选搜索 | 必须实现第 7 节列出的搜索、日期、枚举、校区等筛选，并同步影响列表和导出。 | 筛选只改列表，不改统计或导出。 |
| 主列表/看板 | 必须实现第 6 节列表字段，空状态、加载失败、分页/排序规则可用。 | 字段缺失、字段名不统一、展示原始 ID 或原始时间。 |
| 详情/弹窗 | 必须和列表同源，展示第 6 节详情字段和第 8 节操作结果。 | 列表和详情同一字段显示不同口径。 |
| 导入导出/审计 | 本页有导入、导出、流水、历史时，必须与页面字段和权限一致。 | 导出列多于或少于 PRD，或导出绕过权限。 |

### 15.2 字段落地规则

| 类型 | 必须落实 |
|---|---|
| 展示字段 | 第 6 节出现的字段必须全部可见或有明确空状态，不得用旧字段名替代。 |
| 编辑字段 | 可编辑字段必须有默认值、必填规则、格式规则、保存后回显规则。 |
| 状态字段 | 第 9 节状态必须有进入条件、退出条件、禁止操作。 |
| 金额/课时/次数 | 必须引用 05 数据口径和 09 数据模型，不得页面本地重算核心口径。 |
| 日期时间 | 列表展示日期用统一格式，详情需要精确时间时再展示分钟级时间。 |
| 内部字段 | 记录 ID、流水 ID、调试字段、导入批次默认不展示给业务用户，除非本页明确是审计页。 |

### 15.3 操作契约

| 操作类型 | 复刻要求 |
|---|---|
| 新增/编辑 | 必须按第 8 节校验输入、保存事实表、刷新列表和详情。 |
| 删除/作废 | 默认优先作废或隐藏，不得物理删除影响财务、权益、排课、会员的历史事实。 |
| 转化/关联 | 必须保留来源关系，例如线索、学员、订场、会员之间的关联键。 |
| 导入 | 必须先预览校验，再提交；失败行不写入；结果要可追溯。 |
| 导出 | 导出列必须和本页字段清单一致，并服从当前筛选和账号权限。 |
| 高风险写入 | 涉及财务、权益、会员、订场、排课完成时，必须同时满足 10 和 11 的安全/验收规则。 |

### 15.4 数据与接口契约

| 项 | 要求 |
|---|---|
| 数据来源 | 第 11 节列出的接口/读模型是本页默认来源；不得另起页面私有口径。 |
| 页面缓存 | 保存、作废、导入、转化后必须刷新本页和受影响页面的数据。 |
| 跨页一致 | 本页字段如出现在财务、经营分析、客户生命周期、教练端，必须和对应页面同源。 |
| 兼容数据 | 历史字段只允许映射到标准字段，不得继续作为新字段展示。 |
| 空值处理 | 空值必须显示业务可理解的空状态，不得显示 undefined、null、NaN。 |

### 15.5 权限与异常

| 场景 | 要求 |
|---|---|
| 管理员 | 可见和可操作范围按 01 角色权限执行。 |
| 校区权限 | 受校区范围限制的账号只能看授权校区数据。 |
| 教练权限 | 教练只能看本人课程、本人学员、本人反馈。 |
| 接口失败 | 页面提示重试，不产生半条业务记录。 |
| 权限不足 | 不展示越权数据，操作入口不可用或提交失败并提示。 |
| 数据冲突 | 重复手机号、重复报名、余额不足、排课冲突等必须提示冲突原因。 |
