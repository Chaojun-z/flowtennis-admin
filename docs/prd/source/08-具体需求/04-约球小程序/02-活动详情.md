## 1. 页面目标

展示单个约球活动的时间、地点、规则、人数、费用、报名状态和操作入口。

## 2. 使用角色

- 约球用户

## 3. 页面入口

| 项 | 内容 |
|---|---|
| 端 | 约球小程序 |
| 一级模块 | 约球小程序 |
| 页面名称 | 活动详情 |
| 页面 ID / 面板 | match-mini-detail |
| 菜单路径 | 约球小程序 / 活动详情 |

## 4. 功能范围

### 4.1 必须支持

- 查看活动详情
- 查看报名人数和候补状态
- 查看费用说明和活动规则
- 报名或取消报名
- 发起评价或确认到场入口

### 4.2 不在本页处理

- 不改变统一数据口径
- 不绕过权限和安全规则
- 不直接改写其他模块事实数据

## 5. 页面结构

| 区域 | 内容 | 复现要求 |
|---|---|---|
| 顶部摘要 | 关键数量、状态或待办 | 说明口径和刷新条件 |
| 筛选工具栏 | 搜索、日期、校区、状态等 | 筛选后列表和统计同步 |
| 主内容 | 表格、卡片、日程、列表或表单 | 空状态、失败态、分页固定 |
| 详情/弹窗 | 查看或维护单条记录 | 字段和列表同源 |
| 审计/协议 | 日志、绑定、协议或通知记录 | 可追溯 |

## 6. 字段清单

| 区域 | 字段 / 指标 | 来源 / 口径 | 展示或编辑规则 |
|---|---|---|---|
| 详情 | 活动名称、时间、地点、规则 | matches | 后台活动信息 |
| 详情 | 人数上限、已报名、候补 | registrations | 实时统计 |
| 详情 | 费用、AA 规则、支付状态 | fee_splits | 后台费用确认后展示 |
| 详情 | 本人报名状态 | registration status | 决定按钮 |

## 7. 筛选、搜索与排序

| 能力 | 字段 | 规则 |
|---|---|---|
| 无 | 详情页按活动 ID | 不做复杂筛选 |

## 8. 核心操作规则

| 操作 | 触发入口 | 业务规则 | 结果影响 |
|---|---|---|---|
| 报名 | 报名按钮 | 未报名且可报名；必要时补手机号 | 生成 registration |
| 取消报名 | 取消按钮 | 按规则记录取消原因和责任 | 更新报名状态 |
| 评价 | 评价入口 | 活动完成后可评价 | 写评价记录 |

## 9. 状态与流转规则

| 对象 | 状态 | 进入条件 | 退出或禁止条件 |
|---|---|---|---|
| 报名 | 未报名 | 用户未参与 | 可报名 |
| 报名 | 已报名 | 报名成功 | 可取消或查看费用 |
| 报名 | 候补 | 满员后候补 | 转正或取消 |
| 活动 | 已取消 | 后台取消 | 禁止报名 |

## 10. 数据关系

| 关系 | 上游 | 本页使用 | 下游影响 |
|---|---|---|---|
| 活动到报名 | matches | 报名目标 | 我的约球 |
| 报名到费用 | registrations/fee_splits | 费用责任 | 后台费用 |

## 11. 接口与数据来源

| 用途 | 接口 / 读模型 | 方法 | 说明 |
|---|---|---|---|
| 详情 | /matches/:id | GET | 活动详情 |
| 报名 | /matches/:id/register | POST | 报名 |
| 取消报名 | /matches/:id/cancel-register | POST | 取消报名 |
| 评价 | /matches/:id/rating | POST | 评价 |

## 12. 权限规则

| 角色 | 可见范围 | 可操作范围 |
|---|---|---|
| 约球用户 | 本人活动和报名 | 查看、报名、取消、维护资料 |
| 管理员 | 后台约球管理 | 审核、订场、费用确认 |

## 13. 异常场景

| 场景 | 页面表现 | 处理规则 |
|---|---|---|
| 无数据 | 业务空状态 | 不显示技术错误 |
| 接口失败 | 提示重试 | 不得半写入 |
| 权限不足 | 无权限提示 | 不得暴露越权数据 |
| 绑定缺失 | 提示完成绑定 | 不自动冒用身份 |
| 历史数据 | 按兼容规则展示 | 不扩散旧字段 |

## 14. 验收标准

- 可报名活动能成功报名并在我的约球出现
- 已报名用户不能重复报名
- 取消报名后后台报名名单同步
- 后台取消后详情不可报名
- 费用信息和后台确认结果一致

## 15. 复刻级补充要求

本节是本页面交付给研发、测试或 AI 复刻时的硬性检查项。复刻“活动详情”时，不能只实现菜单入口或静态页面，必须把本页字段、操作、状态、接口、权限、异常和验收闭环全部落地。

### 15.1 页面区域完整性

| 区域 | 复刻要求 | 不合格表现 |
|---|---|---|
| 页面入口 | 必须按第 3 节入口、页面 ID、菜单路径接入。 | 只有菜单但不能打开，或打开后不是本页数据。 |
| 顶部摘要 | 必须实现第 5/6 节定义的卡片或摘要，并说明全局、筛选、当前视图口径。 | 卡片数字和列表/经营分析不一致。 |
| 筛选搜索 | 必须实现第 7 节列出的搜索、日期、枚举、校区等筛选，并同步影响列表和导出。 | 筛选只改列表，不改统计或导出。 |
| 主列表/看板 | 必须实现第 6 节列表字段，空状态、加载失败、分页/排序规则可用。 | 字段缺失、字段名不统一、展示原始 ID 或原始时间。 |
| 详情/弹窗 | 必须和列表同源，展示第 6 节详情字段和第 8 节操作结果。 | 列表和详情同一字段显示不同口径。 |
| 导入导出/审计 | 本页有导入、导出、流水、历史时，必须与页面字段和权限一致。 | 导出列多于或少于 PRD，或导出绕过权限。 |

### 15.2 字段落地规则

| 类型 | 必须落实 |
|---|---|
| 展示字段 | 第 6 节出现的字段必须全部可见或有明确空状态，不得用旧字段名替代。 |
| 编辑字段 | 可编辑字段必须有默认值、必填规则、格式规则、保存后回显规则。 |
| 状态字段 | 第 9 节状态必须有进入条件、退出条件、禁止操作。 |
| 金额/课时/次数 | 必须引用 05 数据口径和 09 数据模型，不得页面本地重算核心口径。 |
| 日期时间 | 列表展示日期用统一格式，详情需要精确时间时再展示分钟级时间。 |
| 内部字段 | 记录 ID、流水 ID、调试字段、导入批次默认不展示给业务用户，除非本页明确是审计页。 |

### 15.3 操作契约

| 操作类型 | 复刻要求 |
|---|---|
| 新增/编辑 | 必须按第 8 节校验输入、保存事实表、刷新列表和详情。 |
| 删除/作废 | 默认优先作废或隐藏，不得物理删除影响财务、权益、排课、会员的历史事实。 |
| 转化/关联 | 必须保留来源关系，例如线索、学员、订场、会员之间的关联键。 |
| 导入 | 必须先预览校验，再提交；失败行不写入；结果要可追溯。 |
| 导出 | 导出列必须和本页字段清单一致，并服从当前筛选和账号权限。 |
| 高风险写入 | 涉及财务、权益、会员、订场、排课完成时，必须同时满足 10 和 11 的安全/验收规则。 |

### 15.4 数据与接口契约

| 项 | 要求 |
|---|---|
| 数据来源 | 第 11 节列出的接口/读模型是本页默认来源；不得另起页面私有口径。 |
| 页面缓存 | 保存、作废、导入、转化后必须刷新本页和受影响页面的数据。 |
| 跨页一致 | 本页字段如出现在财务、经营分析、客户生命周期、教练端，必须和对应页面同源。 |
| 兼容数据 | 历史字段只允许映射到标准字段，不得继续作为新字段展示。 |
| 空值处理 | 空值必须显示业务可理解的空状态，不得显示 undefined、null、NaN。 |

### 15.5 权限与异常

| 场景 | 要求 |
|---|---|
| 管理员 | 可见和可操作范围按 01 角色权限执行。 |
| 校区权限 | 受校区范围限制的账号只能看授权校区数据。 |
| 教练权限 | 教练只能看本人课程、本人学员、本人反馈。 |
| 接口失败 | 页面提示重试，不产生半条业务记录。 |
| 权限不足 | 不展示越权数据，操作入口不可用或提交失败并提示。 |
| 数据冲突 | 重复手机号、重复报名、余额不足、排课冲突等必须提示冲突原因。 |

### 15.6 AI 可执行验收

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| PAGE-01 | 打开页面 | 能通过第 3 节入口打开“活动详情”，页面标题和数据域正确。 |
| PAGE-02 | 字段完整 | 第 6 节字段在列表、详情、导出或审计入口中按定义出现。 |
| PAGE-03 | 筛选一致 | 第 7 节筛选后，列表、顶部摘要、导出结果一致。 |
| PAGE-04 | 操作闭环 | 第 8 节每个操作执行后，相关页面和读模型数据同步。 |
| PAGE-05 | 状态正确 | 第 9 节状态流转符合进入/退出/禁止条件。 |
| PAGE-06 | 权限隔离 | 不同角色、不同校区、教练本人范围按第 12 节隔离。 |
| PAGE-07 | 异常可控 | 第 13 节异常不产生脏数据，不暴露内部错误。 |
| PAGE-08 | PRD 自包含 | 复刻本页不需要打开 PRD 目录以外的旧 docs 文档。 |
