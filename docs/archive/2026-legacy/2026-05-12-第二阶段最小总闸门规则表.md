## 1. 当前统一入口

### 本地前置

- 命令：`npm run gate:local`
- 编排内容：
  - `npm test`
  - `npm run guard:finance`
- 作用：
  - 作为第二阶段默认本地前置总入口
  - 先拦结构回归、页面 / 接口静态回归、财务固定快照回归

### staging 验收前

- 命令：`npm run gate:staging`
- 编排内容：
  - `npm run gate:local`
  - `npm run staging:ensure-login-minimal:check`
  - `npm run staging:ensure-browse-minimal:check`
- 作用：
  - 作为 staging 正式验收前统一入口
  - 在本地前置基础上，再检查 staging 最小登录链路与关键浏览链路

### 主干收口前

- 命令：`npm run gate:main`
- 编排内容：
  - `npm run gate:staging`
- 作用：
  - 作为当前第二阶段主干收口前统一入口
  - 在新 `main` 正式恢复前，实际口径仍以 `origin/thread26-staging-latest` + `staging` 验收为准

## 3. 变更类型 -> 必跑门禁

| 变更类型 | 必跑门禁 | 说明 |
| --- | --- | --- |
| 财务相关链路改动 | `npm run gate:local` -> `npm run gate:staging` -> `npm run gate:main` | 适用于 `purchases / entitlements / entitlement_ledger / courts / financial_ledger / membership_orders / membership_benefit_ledger`、财务页聚合、`api/index.js` 启动/repair 逻辑 |
| 登录 / 初始化 / 高危写链改动 | `npm run gate:local` -> `npm run gate:staging` | 至少覆盖默认测试、财务回归、staging 登录最小检查 |
| staging / 环境 / 导入链改动 | `npm run gate:local` -> `npm run gate:staging` | 涉及环境隔离、staging 数据脚本、最小验收链路时必须跑 |
| 关键后台页聚合接口改动 | `npm run gate:local` -> `npm run gate:staging` | 当前重点是 `/page-data/finance`、`/page-data/workbench` |
| 一般后台功能改动 | `npm run gate:local` | 如后续确认触达高危边界，再升级到 `staging` / `main` 层 |

## 6. 当前不纳入本轮默认总入口的项目

以下内容当前仅保留现有入口，不在本轮一次性塞入默认总闸门：

1. `tests/` 目录下尚未纳入 `npm test` 的其余测试文件
2. `npm run staging-data:export`
3. `npm run staging-data:sanitize`
4. `npm run staging-data:import`
5. 所有 `repair / import / cleanup / finalize` 写入类脚本

原因：

1. 本轮目标是最小补口，不是大规模 CI 扩容
2. 不允许把 repair / import 脚本重新混回功能验收流
3. staging 数据刷新链路属于环境维护入口，不等于每次功能改动都必须执行
