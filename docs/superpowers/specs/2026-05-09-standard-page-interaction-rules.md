# 标准页交互规则清单

## 1. 文档目的

本文件沉淀后台标准页的通用交互规则。

后续任何新页面如果接入标准页体系，都必须优先遵守本文件，而不是自行定义交互。

## 2. 空值规则

1. 所有无数据场景统一显示 `-`
2. 禁止出现 `—`
3. 适用范围包括：
   - 表格单元格
   - 统计卡副信息
   - 详情页只读字段
   - 弹窗中的关联信息
   - 筛选回显为空值的场景

补充规则：

1. 真实 0 不属于空值
2. `0`、`0/10`、`¥0` 必须正常显示

## 3. 列表数据处理顺序

列表统一处理顺序为：

`原始数据 -> 搜索 / 筛选 -> 排序 -> 分页 -> 当前页渲染`

约束：

1. 分页不参与筛选
2. 分页不参与排序
3. 搜索和筛选永远基于全量结果集执行

## 4. 搜索规则

1. 标准列表页默认支持回车查询
2. 标准列表页默认支持点查询按钮执行
3. 第一版不默认输入即搜
4. 搜索执行后回第一页
5. 搜索不清空已选筛选项

## 5. 筛选规则

1. 下拉、日期、搜索框采用统一视觉与交互
2. 筛选执行后回第一页
3. 重置后清空条件并回第一页
4. 重置后保留页面默认排序规则
5. 筛选逻辑基于全量结果集
6. 标准下拉筛选项必须展示当前基础数据集内的数量，格式为 `选项（数量）`
7. 数量统计不受分页影响；已接入标准页体系的学员管理、排课表和后续标准页都必须复用同一套计数能力

## 6. 排序规则

1. 排序采用三态：
   - 默认
   - 升序
   - 降序
2. 点击顺序固定：
   `默认 -> 升序 -> 降序 -> 默认`
3. 排序列高亮统一
4. 排序后回第一页
5. 排序只作用于筛选后的完整结果集

## 7. 列筛选规则

1. 列筛选入口统一放在表头右侧
2. 已筛选状态必须有高亮
3. 列筛选与全局筛选可叠加
4. 列筛选执行后回第一页

## 8. 分页规则

### 8.1 每页条数

1. 标准值仅支持 `20 / 50 / 100`
2. 默认值使用 `20`
3. 切换每页条数后回第一页
4. 切换后保留当前搜索、筛选、排序条件

### 8.2 页码显示

1. 总页数 `<= 7` 时全部展示
2. 总页数 `> 7` 时采用压缩页码
3. 显示第一页、当前页附近 2 页、最后一页
4. 中间使用 `...`

### 8.3 跳页

1. 支持输入页码跳转
2. 输入只允许正整数
3. 小于 1 时按 1
4. 大于最大页时按最后一页
5. 支持回车跳转

### 8.4 单页和空结果

1. 只有 1 页时保留总数与每页条数控件
2. 右侧页码区可隐藏
3. 空结果时分页区左侧信息仍保留

### 8.5 删除后的回退

1. 删除后当前页空掉时自动回上一有效页
2. 不允许停留在空白页

## 9. 表格滚动规则

1. 标准列表页取消表格内部纵向滚动
2. 标准列表页使用页面整体纵向滚动
3. 表格保留横向滚动
4. 复杂超大明细页可单独评估是否保留内部纵向滚动

## 10. 固定列规则

1. 第一列可作为主标识字段左固定
2. 最后一列可作为操作列右固定
3. 左右固定列与普通列 hover 联动
4. 左右固定列需有统一阴影或边界分隔
5. 固定列与表头必须严格对齐

## 11. 行样式规则

1. 默认单元格单行展示
2. 备注 / 说明类字段允许两行截断
3. hover 背景色统一
4. 选中态统一
5. disabled 和 loading 风格统一

## 12. 操作列规则

1. 操作列默认右固定
2. 文案样式统一
3. hover 样式统一
4. 危险操作使用危险态样式
5. 操作列宽度使用标准档位

## 13. 额度条 / 金额条规则

1. 额度条和余额条纳入标准单元格能力
2. 有值时显示条形底座和真实文本
3. 无值显示 `-`
4. 真实 0 不显示为空
5. 后续课包余额、充值余额、会员额度统一复用

## 14. 弹窗规则

1. 标准弹窗包括：
   - 详情
   - 新增
   - 编辑
   - 删除确认
   - 作废确认
2. 标题区统一
3. 字段布局统一
4. 底部按钮区统一
5. 主按钮 loading 统一
6. 保存失败不关闭
7. 删除必须二次确认
8. 作废必须填写原因

## 15. 保存与删除规则

### 15.1 保存

1. 点击保存后按钮进入 loading
2. 禁止重复点击
3. 保存成功后关闭弹窗并刷新当前页面
4. 刷新时重新计算统计、筛选结果、分页
5. 保存失败不清空用户输入

### 15.2 删除

1. 删除必须二次确认
2. 删除成功后刷新列表
3. 删除导致当前页空掉时自动回上一有效页

## 16. 状态反馈规则

1. toast 成功提示统一
2. toast 失败提示统一
3. toast 警告提示统一
4. 空状态文案统一
5. 加载状态文案和样式统一

## 17. 新线程使用规则

后续新线程如果要做标准页相关工作，必须优先阅读：

1. 标准页组件库设计方案
2. 本交互规则清单
3. 对应样板页规格

不允许绕过这些规则直接自定义页面交互。
