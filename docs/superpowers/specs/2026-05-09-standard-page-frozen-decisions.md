# 标准页已冻结决策清单

## 1. 文档目的

本文件用于列出已经明确冻结、不应在后续线程中反复讨论的决策。

## 2. 已冻结决策

1. 第一阶段标准页体系只针对管理端后台，不针对教练网页端。
2. 教练网页端后续如果要统一，应单独定义教练端页面标准。
3. 第一阶段试点页固定为：
   - 学员管理
   - 排课表
4. 第一阶段先局部验证，不做全局表格壳替换。
5. 路线固定为：
   - 先局部验证
   - 后全局收编能力
   - 再逐页迁移
6. 学员管理是第一标准样板页。
   - 2026-05-21 已按当前线上主干冻结为标准样板页。
   - 后续标准页以学员管理的列表、筛选、分页、空态、弹窗口径为参考。
7. 学员页标准样板取消表格内部纵向滚动，只保留页面纵向滚动。
8. 学员页保留横向滚动。
9. 学员页保留第一列【学员】左固定。
10. 学员页保留最后一列【操作】右固定。
11. 学员页【课包/课时】额度条样式保留，并提升为标准单元格能力。
12. 搜索和筛选必须基于全量数据执行，不能只作用于当前页。
13. 列表统一处理顺序固定为：
    `原始数据 -> 搜索/筛选 -> 排序 -> 分页 -> 当前页渲染`
14. 所有空值统一显示 `-`，禁止出现 `—`。
15. 真实 `0` 不属于空值，必须正常显示。
16. 标准分页器必须支持：
    - `20 / 50 / 100`
    - 压缩页码
    - 跳页
17. 默认每页条数为 `20`。
18. 切换每页条数后回第一页。
19. 搜索、筛选、排序后回第一页。
20. 删除后如果当前页空掉，自动回上一有效页。
21. 第一阶段不承诺“页面滚动时表头吸顶”。
22. Web 后台图标统一使用 `Lucide`。
23. 小程序暂不接 icon 库，继续走本地 svg / 资源集中管理。
24. 从现在开始，后台新增图标必须统一使用 `Lucide`。
25. 页面内禁止继续新增散写内嵌 SVG 图标。
26. 当前不要求全站立刻替换旧图标，后续待标准页体系稳定后分批迁移。
27. 学员管理冻结后，第二个标准页按最新决策改为【排课表】。
28. 排课表第一版标准化优先覆盖列表、筛选、分页、固定列、空态、加载态、失败态；不顺手改排课保存、扣课、通知、反馈等业务逻辑。

## 3. 使用规则

后续新线程如发现上述任一项与自己的理解冲突，默认以本文件为准，不重新开启无必要讨论。
