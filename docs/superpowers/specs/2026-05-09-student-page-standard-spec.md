# 学员管理标准样板页规格

## 1. 文档目的

本文件用于冻结【学员管理】作为第一版标准样板页的最终规格。

它的用途不是让后续页面复制学员页代码，而是明确：

1. 哪些设计和交互要保留
2. 哪些地方要调整成标准
3. 哪些能力要从学员页中抽象进标准库
4. 后续其它标准页应该以什么为参考

## 2. 页面定位

学员管理承担三重角色：

1. 第一版标准页样板
2. 第一版标准表格样板
3. 第一版标准分页器样板

首批需要在这个页面上验证的标准能力：

1. 页面骨架
2. 搜索与筛选
3. 标准表格
4. 左右固定列
5. 额度条单元格
6. 标准分页器
7. 详情弹窗
8. 编辑弹窗
9. 保存与删除交互

## 3. 页面骨架规格

区块顺序固定为：

1. 页面标题区
2. 解释条
3. 统计卡区
4. 搜索 / 筛选区
5. 主操作区
6. 表格区
7. 分页区

约束：

1. 不允许调整顺序
2. 不允许新增表格内部纵向滚动容器
3. 分页区固定放在表格区下方

## 4. 保留项

以下内容作为样板页保留：

1. 当前页面整体信息层级
2. 第一列【学员】左固定
3. 最后一列【操作】右固定
4. 【课包/课时】额度条展示样式
5. 当前主筛选结构
   - 搜索
   - 类型
   - 来源
   - 负责教练
6. 当前操作链路
   - 查看
   - 课包
   - 编辑
7. 当前统计卡分组思路

## 5. 修改项

以下内容必须调整成标准：

### 5.1 取消表格内部纵向滚动

调整目标：

1. 标准列表页不再使用表格内部纵向滚动
2. 页面整体自然纵向滚动
3. 表格只保留横向滚动

原因：

1. 避免分页和内部滚动叠加
2. 更符合标准 SaaS 列表页体验
3. 避免“每页 20 条但首屏只能看到 10 多条”的不一致感

### 5.2 分页器标准化

必须增加：

1. 每页条数切换 `20 / 50 / 100`
2. 压缩分页显示
3. 跳页能力

### 5.3 空值统一

1. 全部空值显示 `-`
2. 禁止出现 `—`
3. 真实 0 与空值必须区分

### 5.4 固定列标准化

1. 左固定主标识列
2. 右固定操作列
3. hover 联动
4. 固定列阴影或边界分隔

## 6. 表格规格

### 6.1 表格滚动规则

1. 页面纵向滚动
2. 表格保留横向滚动
3. 左右固定列在横向滚动时始终可见

### 6.2 固定列规则

1. 第一列【学员】左固定
2. 最后一列【操作】右固定
3. 固定列与普通列行 hover 联动
4. 固定列和表头严格对齐
5. 固定列边界要有统一阴影或分隔线

### 6.3 单元格规则

1. 默认单元格单行显示
2. 备注类字段允许两行截断
3. 长文本不允许无限撑高整行
4. 空值统一 `-`
5. 状态和摘要使用统一文案样式

## 7. 额度条单元格规格

### 7.1 定位

【课包/课时】这一列作为标准单元格样式保留，并提升为通用能力。

后续复用场景：

1. 学员课包余额
2. 订场用户充值余额
3. 会员额度
4. 其他配额 / 余额场景

### 7.2 展示规则

1. 统一浅底进度条样式
2. 文本居中或左内边距统一
3. 有值时显示真实值
   - 例如 `16/20`
   - 例如 `¥4,826`
4. 无数据显示 `-`
5. 真实 0 不是空值，需正常显示

### 7.3 标准命名

后续标准库内建议抽象为：

1. `quota-bar`
2. `amount-bar`

## 8. 搜索与筛选规格

### 8.1 数据口径

固定流程：

`全量数据 -> 搜索 / 筛选 -> 排序 -> 分页 -> 当前页展示`

### 8.2 搜索规则

1. 支持回车查询
2. 支持点查询按钮执行
3. 第一版不默认输入即搜

### 8.3 筛选联动规则

1. 搜索后回第一页
2. 筛选后回第一页
3. 排序后回第一页
4. 切换每页条数后回第一页

### 8.4 筛选布局

1. 搜索框在最左
2. 核心筛选项同一行
3. 主操作区与筛选区保持标准位置关系

### 8.5 筛选数量

1. 标准下拉筛选项展示数量，格式为 `成人（12）`
2. 数量来自当前页面基础数据集，不受分页影响
3. 后续接入标准页体系的页面必须复用公共计数能力

## 9. 分页器规格

### 9.1 布局

左侧：

1. `共 X 条`
2. 每页条数切换器

右侧：

1. `上一页`
2. 压缩页码
3. `下一页`
4. `跳至 [输入框] 页`

### 9.2 每页条数规则

1. 标准值仅支持 `20 / 50 / 100`
2. 默认值使用 `20`
3. 切换后回第一页
4. 切换后保留当前搜索、筛选、排序条件

### 9.3 页码显示规则

1. 总页数 `<= 7` 时全部展示
2. 总页数 `> 7` 时采用压缩页码
3. 显示第一页、当前页附近 2 页、最后一页
4. 中间使用 `...`

示例：

1. `1 2 3 4 5 6 7`
2. `1 ... 8 9 10 11 12 ... 50`
3. `1 2 3 4 5 ... 50`
4. `1 ... 46 47 48 49 50`

### 9.4 跳页规则

1. 输入只允许正整数
2. 小于 1 时按 1
3. 大于最大页时按最后一页
4. 支持回车跳转
5. 跳页后保留当前筛选和排序

### 9.5 单页规则

1. 只有 1 页时保留左侧信息
2. 右侧页码区可隐藏
3. 不允许整块分页区消失

### 9.6 删除后的页码回退

1. 删除后如果当前页空了，自动回上一有效页
2. 不允许出现空白页

## 10. 操作列规格

### 10.1 交互规则

1. 操作列默认右固定
2. 文案样式统一
3. hover 态统一
4. 危险操作使用危险态样式

### 10.2 学员页操作项

第一版保留：

1. 查看
2. 课包
3. 编辑

## 11. 弹窗规格

学员页需要验证两类标准弹窗：

1. 详情弹窗
2. 编辑弹窗

统一规则：

1. 标题区统一
2. 字段布局统一
3. 底部按钮区统一
4. 保存按钮 loading 统一
5. 删除确认统一
6. 保存失败不关闭弹窗

## 12. 暂不处理项

第一版先不纳入：

1. 页面滚动时表头吸顶
2. 复杂批量操作
3. 高级列显隐
4. 复杂多条件列筛选组合

## 13. 验收点

学员管理标准样板页完成后，至少满足以下验收要求：

1. 没有内部纵向滚动
2. 左右固定列正常工作
3. 横向滚动时固定列不抖动
4. 分页器支持 `20 / 50 / 100`
5. 分页器支持压缩页码
6. 分页器支持跳页
7. 搜索筛选基于全量数据
8. 空值全部显示 `-`
9. 额度条样式保留且可复用
10. 查看 / 编辑 / 保存 / 删除交互保持稳定
