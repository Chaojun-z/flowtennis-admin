# 标准页改造验收清单

## 1. 文档目的

本文件用于作为标准页改造的验收门禁。

任何页面接入标准页体系后，都不应只看“样式像不像”，而必须按清单确认：

1. 功能没坏
2. 交互没退化
3. 标准没跑偏

## 2. 通用验收项

### 2.1 数据口径

必须确认：

1. 搜索基于全量数据执行
2. 筛选基于全量数据执行
3. 排序基于筛选后的完整结果集执行
4. 分页只负责展示切片

### 2.2 空值规则

必须确认：

1. 全部空值显示 `-`
2. 没有 `—`
3. 真实 0 正常显示，不被误判为空

### 2.3 分页规则

必须确认：

1. 支持 `20 / 50 / 100`
2. 切换每页条数后回第一页
3. 搜索后回第一页
4. 筛选后回第一页
5. 排序后回第一页
6. 压缩页码显示正确
7. 跳页输入生效
8. 跳页不清空筛选和排序

### 2.4 删除回退规则

必须确认：

1. 删除成功后列表刷新
2. 当前页删空时自动回上一有效页
3. 不出现空白页

### 2.5 固定列规则

必须确认：

1. 左固定列稳定
2. 右固定列稳定
3. 横向滚动时固定列不抖动
4. hover 联动正常
5. 表头和表体对齐正常

### 2.6 表格滚动规则

标准列表页必须确认：

1. 不存在内部纵向滚动
2. 页面整体纵向滚动正常
3. 表格横向滚动正常

### 2.7 额度条 / 金额条规则

必须确认：

1. 有值时显示正确
2. 空值显示 `-`
3. 0 值显示正常
4. 样式未变形

### 2.8 弹窗规则

必须确认：

1. 详情弹窗正常打开
2. 编辑弹窗正常打开
3. 保存按钮 loading 正常
4. 保存失败不关闭
5. 删除二次确认正常

## 3. 学员管理专属验收项

### 3.1 列表

1. 第一列【学员】左固定
2. 最后一列【操作】右固定
3. 【课包/课时】额度条展示正常
4. 搜索、类型、来源、负责教练筛选正常

### 3.2 分页

1. 默认 `20条/页`
2. 支持 `50条/页`
3. 支持 `100条/页`
4. 压缩页码显示正常
5. 支持跳页

### 3.3 业务链路

1. 查看详情正常
2. 编辑资料正常
3. 保存资料正常
4. 删除学员正常
5. 全量筛选逻辑未被破坏

## 4. 排课表专属验收项

1. 使用统一分页器
2. 支持 `20 / 50 / 100` 每页条数
3. 搜索、状态、校区、课程类型筛选后回第一页
4. 第一列【日期】左固定
5. 最后一列【操作】右固定
6. 空数据、加载中、加载失败使用统一状态样式
7. 不改变排课保存、扣课、取消、反馈等业务逻辑

## 5. 验收失败处理规则

如果以下任一问题出现，视为验收不通过：

1. 搜索或筛选变成只作用于当前页
2. 分页切换后逻辑异常
3. 固定列错位
4. 空值规则不统一
5. 删除后出现空白页
6. 额度条 0 值和空值显示错误
7. 学员详情 / 编辑链路被改坏

## 6. 新线程执行要求

后续线程改完标准页相关功能后，必须以本清单逐项自查，不允许只凭视觉判断“差不多好了”。

补充要求：

1. 第一阶段验收只针对试点页，不代表允许直接全局替换旧页面
2. 只有当试点页稳定通过验收后，相关能力才允许收编进全局标准能力层
3. 全局能力收编后，仍需逐页迁移接入，不允许一次性全站替换
