# 财务每日快照取用手册

## 每日自动备份在哪里

GitHub Actions -> Finance Daily Snapshot -> 对应日期运行记录 -> Artifacts -> finance-daily-snapshot-<run_id>

## 快照用途

1. 证明某一天财务安全版本。
2. 作为操作前/操作后对比来源。
3. 发生异常时，用于按 `operationId` / `batchId` 定位受影响记录。

## 取用步骤

1. 打开 GitHub Actions。
2. 进入 `Finance Daily Snapshot`。
3. 选择需要恢复到的日期。
4. 下载 artifact。
5. 解压后找到 `finance-daily-snapshot-*.json`。
6. 先只读核对，不直接写生产。

## 恢复前要求

1. 先生成恢复前快照。
2. 先确认线上 `/api/diag` 是 `flowtennis-ue`。
3. 优先按 `operationId` / `batchId` 回滚。
4. 整库或整表恢复必须用户明确同意。
