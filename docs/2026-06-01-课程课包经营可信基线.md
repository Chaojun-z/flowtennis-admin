## 2. 已确认范围

本基线只覆盖：

1. 非课包直接课程收入。
2. 课包购买收入。
3. 课包消耗/核销形成的已入账收入。
4. 财务总览、收入流水、学员管理三个页面对课程/课包口径的一致性。

本基线不覆盖：

1. 会员充值收入，见 `2026-06-02 会员经营可信基线`。
2. 会员订场、散客订场、约球订场，见 `2026-06-04 订场用户经营可信基线`。
3. 2026-06-01 之后未经再次核对的新增课程/课包数据。

## 5. 后续新增数据规则

本基线是 2026-06-01 的人工确认锚点，不会自动滚动。

后续如果有人在系统里新增课程、课包购买或消课：

1. 线上页面应实时按业务口径变化。
2. 每日经营快照应记录新增后的真实状态。
3. 本文件中的 2026-06-01 确认值不自动修改。
4. 只有新增数据再次完成核对后，才能生成新的经营可信基线。

---

## 6. 禁止事项

1. 禁止用本文件覆盖 `config/finance-baseline.v2.json`。
2. 禁止把本文件当成 `npm run guard:finance` 的门禁基线。
3. 禁止用本文件替代会员或订场用户的独立经营可信基线。
4. 禁止在未核对新增数据的情况下，把每日快照直接升级为可信基线。
