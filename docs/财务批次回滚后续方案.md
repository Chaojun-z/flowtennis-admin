# 财务批次回滚后续方案

## 原则

1. 默认按 `operationId` / `batchId` 回滚单次操作。
2. 回滚前必须先生成恢复前快照。
3. 回滚后必须生成恢复后快照。
4. 回滚后必须跑 `validate:finance-operation` 或专门的反向校验。
5. 整表/整库恢复必须用户明确同意。

## 第一版只支持 dry-run

脚本名建议：

```bash
scripts/rollback-finance-operation-dry-run.js
```

输入：

```bash
node scripts/rollback-finance-operation-dry-run.js --snapshot <snapshot.json> --operation-id <operationId>
```

输出：

1. 涉及表。
2. 涉及记录 ID。
3. 将删除/恢复/反向冲正的动作。
4. 风险提示。

## 禁止事项

1. 不允许默认写生产。
2. 不允许没有快照就回滚。
3. 不允许找不到 `operationId` 时靠猜。
