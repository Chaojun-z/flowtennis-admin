# 财务真实操作演练手册

## 目标

用一笔可控真实业务动作证明：

1. 操作前快照可用。
2. 业务录入后数据确实变化。
3. 操作后快照可用。
4. `validate:finance-operation` 能验证正确变化。
5. 线上页面或登录态 API 能看到变化。

## 演练前停止条件

1. `/api/diag` 不是 `flowtennis-ue`，停止。
2. 本地 `.env` 目标和线上 diag 不一致，停止。
3. 没有用户确认真实操作内容，停止。
4. 没有操作前快照，停止。

## 推荐演练动作

优先选低金额、可撤销、用户明确同意的动作。

推荐顺序：

1. 散客订场现金/微信收款，金额 1 元或用户指定金额。
2. 买课包测试订单，金额用户指定。
3. 会员储值测试订单，金额用户指定。

不要擅自创建虚假生产数据。

## 操作步骤

1. 生成操作前快照：

```bash
npm run snapshot:finance
```

2. 记录输出路径为 `BEFORE_SNAPSHOT`。

3. 用户在系统里完成真实业务操作，或用户明确授权由 AI 操作。

4. 生成操作后快照：

```bash
npm run snapshot:finance
```

5. 执行变化校验：

```bash
npm run validate:finance-operation -- --before "$BEFORE_SNAPSHOT" --after "$AFTER_SNAPSHOT" --type court-booking --amount 1
```

6. 登录态线上核对：

- 财务总览数字变化。
- 收入流水出现新增收款。
- 已入账流水按动作口径变化。
- 对应业务页能看到业务记录。

## 验收输出

必须记录：

1. 操作类型。
2. 操作金额。
3. `operationId` / `batchId`。
4. 操作前快照路径。
5. 操作后快照路径。
6. 校验命令结果。
7. 线上 API 或页面核对结果。
